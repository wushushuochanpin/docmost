# 已接受的产品范围

认证中心是身份权威，Docmost 保留用户 ID、成员、空间角色和页面权限。采用成熟 OIDC 客户端加中心托管短事务扩展，复用现有界面；不复制扫码页、不接中心角色管理。

1. AC01：功能默认关闭，启用后用户可从登录页进入中心托管页；保持密码登录和邀请流程。
2. AC02：老用户在已登录账户设置重新验证本地密码后绑定中心身份；邮箱、手机号、昵称均不得自动合并。
3. AC03：未绑定中心身份明确拒绝，提示先完成邀请/本地登录及绑定。邀请开户沿用已有验证流程，不自动创建或扩大成员权限。
4. AC04：安全回调验证后才创建随机本地会话，保留本地文档、评论、归属和权限。
5. AC05：过期、取消、篡改、重放、中心不可达均安全拒绝；三个独立标签事务不覆盖；同一事务仅成功一次。
6. AC06：退出立即撤销本地会话，中心撤销/禁用和过期影响 API 及已有长连接；旧响应/旧回调不干扰新会话。
7. AC07：Agent/MCP 仍使用本地独立授权，不接受中心令牌作为文档访问凭据。
8. AC08：附加迁移、备份恢复、构建和真实环境验收有独立证据；无法完成的外部验收明确保留。

普通退出仅退出 Docmost；不默认执行全部公司系统退出。全局退出和主动 back-channel 接收以中心已登记合同为前提，本期用在线状态检查闭环，不宣称零延迟。
