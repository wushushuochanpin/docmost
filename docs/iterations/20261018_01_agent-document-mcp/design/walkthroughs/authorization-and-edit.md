# 功能操作说明与剧本

本文为期望行为，非已运行证据。关联UC-01～UC-05及AC-01/03/04/05/07/15/18。

## 场景一：授权并新增文档

前置：用户甲可编辑空间A，空间B不可访问；试用应用已登记且获准；目标文件夹存在。

1. 在Agent选择连接Docmost，进入本站登录与授权页。
2. 核对应用及回调域名，选择空间A、读取和新建文档，保留30天期限；不选择编辑权限。
3. 点击允许，返回Agent。Agent列出A的合法目录，不能看见B。
4. Agent在选定文件夹创建文档，得到已保存结果和URL，用户打开看到正文。
5. Agent尝试修改新文档仍因缺少编辑权限拒绝。用户需要时重新授权增加编辑权限。

异常：拒绝授权返回Agent且无可用连接；授权请求过期返回重新连接入口；创建超时查询原操作，不能再次创建同名文档掩盖未知结果。

## 场景二：人工占用与版本变化

前置：用户甲已授予编辑，用户乙在同一文档编辑；二者可在不同服务器节点。

1. Agent读取编辑上下文并提交修改，收到文档忙，乙的内容不变。
2. 乙保存并退出可编辑状态。Agent重新读取，准备替换一个可编辑段落。
3. 若乙再次编辑并保存，新revision使Agent旧请求拒绝；Agent重新规划。
4. Agent先取得提交资格时，乙打开页面可读，编辑按钮提示稍后重试，不允许先输入后丢弃。
5. 保存完成后乙刷新状态进入编辑，看到新内容。旧离线页重连必须重新同步，本地未提交内容有恢复入口。

异常：持久化断线则显示核对中；用户可以返回目录，不能强制解锁覆盖；恢复后通过操作记录确认结果。

## 场景三：撤销与历史恢复

1. 用户进入设置→Agent连接→目标连接详情，查看授权空间、权限和最近使用时间。
2. 点击撤销，确认框解释已保存内容不会自动回退；取消则不改变授权。
3. 确认后旧令牌与刷新拒绝；弱网时显示待确认并回读状态，不提前显示成功。
4. 操作记录区分撤销前已提交与被撤销终止的请求。
5. 若撤销前已有不满意的修改，打开文档历史比较后恢复；若之后还有人工内容，重新确认当前差异，不自动抹掉后续修改。

## 场景四：管理员紧急关闭

管理员进入工作区Agent策略，关闭写入并确认影响；新写立即拒绝，读取和审计保留。未决操作按提交点规则核对。普通成员既看不到管理入口，也不能通过直达URL执行此操作。
