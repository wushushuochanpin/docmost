# 阶段验收标准

状态：产品验收合同，全部未执行。P0/P1/P2表示交付阶段，不是缺陷严重度。

每条要求均为硬门槛；前阶段未通过不得进入下一阶段。测试数据必须隔离，测试Redis不能复用生产；若检查生产数据只能只读。证据应记录候选版本、环境、输入、输出、前后文档结果和脱敏日志。

| acceptance_id | 最早阶段 | 场景 | 可验收要求 | 必需证据 | 需求ID |
|---|---|---|---|---|---|
| AC-01 | P0 | OAuth授权 | 用户完成登录、明确选择空间与scope；拒绝/非法回调/过期请求不产生可用授权；PKCE、错误audience及代码重放被拒。 | 授权录屏与协议请求脱敏记录 | AUTH-01 |
| AC-02 | P0 | 资源隔离 | 跨用户、跨工作区、跨空间及页面ACL拒绝覆盖搜索摘要、目录、正文、附件元数据、操作结果；创建/编辑scope分别检查；空scope无写权。 | 权限矩阵与零泄露结果 | AUTH-01 |
| AC-03 | P0 | 人工互斥 | 任意用户人工编辑期间Agent零写入；Agent执行期间人工只读；不同节点、同用户、多用户、两个Agent竞争均不双写；人工之间原有协作正常。 | 并发时序、文档前后内容、界面证据 | LOCK-01 |
| AC-04 | P0 | 版本冲突 | 读取后人工改正文、删除内容或改标题，旧revision全部拒绝；检查到写入间再发生变更也不能覆盖；旧block_ref不能复用。 | 前后版本与零变更断言 | LOCK-01 |
| AC-05 | P0 | 幂等重试 | 新建/追加/改标题并发重复请求及响应丢失后重试只生效一次；同键不同载荷拒绝；进程在保存后结果返回前退出也不重复。 | 操作记录与文档计数/内容 | WRITE-01 |
| AC-06 | P0 | 可靠提交 | 持久化失败不得committed；成功后重启仍有内容；索引落后时直接读取可见最新提交；新建内容和目录元信息不可半成功。 | 故障与重启前后持久化证据 | WRITE-01 |
| AC-07 | P0 | 超时恢复 | 超时/断线返回或可查pending/reconciling；核对中不允许重复写；旧执行者失效不能提交；恢复成功后可重新人工编辑。 | 异常时间线、结果查询和恢复记录 | WRITE-01 |
| AC-08 | P0 | 复杂内容保护 | 局部替换之外的表格、附件、评论标记等保持；修改保护区块明确拒绝；未知Markdown不静默降级；整批第N项失败零效果。 | 结构化节点对比与错误结果 | TOOL-01 |
| AC-09 | P1 | 目录创建 | 根只建文件夹；文件只能置于合法文件夹；父目录删除/移动/撤权竞争时失败且无孤立页；新文档出现在现有侧栏。 | 树结构与权限证据 | TOOL-01 |
| AC-10 | P1 | 工具完整性 | 11个工具按scope发现并逐次鉴权；输入边界和返回结果符合PRD；旧四工具既有调用保持兼容。 | 工具清单与成功/拒绝示例 | TOOL-01 |
| AC-11 | P1 | 预览 | 预览不保存、不通知、不持长期锁；预览后内容变化正式提交冲突；preview和正式提交的幂等语义一致。 | 前后数据与操作记录 | TOOL-01 |
| AC-12 | P1 | 编辑分页 | 分页绑定同一revision；中途变化拒绝；截断/保护标志可识别；旧检索快照不能直接获得编辑资格。 | 分页响应和冲突结果 | TOOL-01 |
| AC-13 | P1 | 连接管理 | 列表、详情、缩权、撤销、空态、无权限、断网、重复操作均有恢复路径；直接打开/刷新子路由正常。 | 界面操作证据 | UI-01 |
| AC-14 | P1 | 菜单权限 | 成员可管理自己的连接；管理员可配策略；菜单不可见与直接路由/API拒绝同时成立；管理权限不放开私密正文。 | 角色菜单/路由/API矩阵 | UI-01 |
| AC-15 | P1 | 即时撤销 | 撤销成功后旧token及refresh拒绝；撤销先于提交则零写入，提交先于撤销则记录先后事实；停用用户/ACL变化同样生效。 | 受控竞争时序和令牌拒绝记录 | AUTH-01 |
| AC-16 | P1 | 审计归因 | 每次写入可追溯应用、用户、grant、文档、前后版本及结果；日志无原始令牌/正文；未授权者不能读差异。 | 脱敏日志与审计权限证据 | OPS-01 |
| AC-17 | P1 | 限额边界 | 分钟/日配额、工作区聚合额度、预览和并发限制生效；重试不重复扣写配额；超限给出等待时间。 | 额度临界及恢复结果 | OPS-01 |
| AC-18 | P0 | 恢复基线 | 每次Agent提交可在网页找到可用前版本及归因；历史恢复遵守互斥；后续人工修改存在时需重新比较和确认。 | 历史、恢复操作与内容对比 | LOCK-01 |
| AC-19 | P1 | 旧客户端与租约失效 | 离线/重连/延迟提交不能覆盖Agent结果；未发送人工内容有可见恢复入口；互斥设施异常时关闭Agent写入。 | 旧会话和故障回放 | LOCK-01 |
| AC-20 | P1 | 容量性能 | 按PRD基准读取/预览P95≤2秒、提交P95≤5秒；15秒后pending；至少3用户2客户端50次写入且成功率≥99%。 | 测量条件、延迟分布、试用样本 | OPS-01 |
| AC-21 | P2 | 客户端兼容 | 至少两个独立客户端完成发现→OAuth→工具发现→新建/编辑→撤销；发布精确客户端与协议版本支持矩阵。 | 端到端记录与支持文档 | AUTH-01 |
| AC-22 | P2 | 开发者接入 | 公开说明登记方式、地址、scope、示例、错误恢复、配额及保留期；新开发者按文档能完成沙箱接入。 | 文档链接与独立接入记录 | TOOL-01 |
| AC-23 | P2 | 停用与运维 | 管理员关闭写入后新写拒绝，读取及历史保留；在途操作按提交点处理；未决操作触发告警并可核对。 | 开关演练和告警记录 | OPS-01 |
| AC-24 | P2 | 公开放行 | 14天试用观察完成；无未解决高严重度授权/数据缺陷；P1全回归通过；默认关闭新工作区写入。 | 观察报告与验收签署 | OPS-01 |
