# 交互合同

## 用例、屏幕和流转
| 用例 | 入口→状态→出口 | 证据 |
|---|---|---|
| UC1 OAuth | Agent→需要授权→浏览器登录→授权页 S1→成功回 Agent；拒绝/关闭回 Agent，失败可重试 | AC01/02/04 |
| UC2 API | 令牌列表 S2→创建 S3→仅一次显示 S4→返回 S2 | AC03 |
| UC3 管理 | 连接列表 S2→详情 S5→修改 S6 或撤销确认 S7→S2 | AC03/04/05 |
| UC4 策略 | 工作区策略 S8→禁写/启用→返回并展示生效；用户不得越权 | AC05 |

S1 列应用未经验证标识、请求权限、空间、有效期和策略禁用原因；默认只读，仅允许申请范围内选择。S2 展示类型、名称、范围、权限、状态、到期、最近使用；分页、加载、空、禁用、失败重试。S3 表单含名称、空间、到期、权限及依赖；S4 明文不回显且关闭后无法再看；S5 显示服务端事实；S6 前后差异、OAuth 升权引导重连；S7 明示撤销影响；S8 禁写阻断新写但不删除连接。

## 操作结果矩阵
| action | 前置/禁用 | 成功 | 失败/取消/重试 | 验收 |
|---|---|---|---|---|
| 授权 | 登录、申请有效、至少一个可访问空间 | 回调客户端，管理列表可见 | 拒绝不创建；超时返回并重试；过期重发 | AC01/04 |
| 创建令牌 | 可访问空间、合法到期、读权限 | 一次展示，复制后返回 | 重复提交仅创建一个；错误保留输入；取消无副作用 | AC03 |
| 缩权 | 凭据有效、本人或允许的管理员 | 立即更新且旧 token 受限 | 并发版本冲突刷新；超时先查状态 | AC03/04/05 |
| 升权 | 可选范围不超 ACL/策略；OAuth 须重新授权 | API 明确确认后生效；OAuth 新授权成功后生效 | 拒绝/不兼容不改变旧权限；提示重新连接 | AC03/04 |
| 撤销 | 可管理且非终态 | 幂等终态，后续拒绝 | 取消无变化；失败可重试；超时查状态 | AC03/04/05 |
| 改工作区策略 | 管理员 | 禁写生效且列表显示 | 权限不足或冲突可返回/刷新 | AC05/06 |

所有入口具键盘焦点、清晰标签与错误提示；无权限、网络失败、取消和回调失败均有返回/重试或明确终态。详细视觉复用现有组件。原型在 [权威记录](prototype-authority.md) 中列为实现前待办。
