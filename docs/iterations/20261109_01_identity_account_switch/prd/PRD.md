# Book PRD：无法关联时切换账号

## 背景与目标

用户反馈两次出现 `identity_not_linked`，且期待重新扫码。当前本地源码采用 OIDC 客户端自行接入中心，普通登录允许复用中心会话；本次线上具体原因未查明。目标是接入认证中心统一 Node SDK，并在不能匹配 Book 账号时提供明确、安全的切换身份和绑定指引。

## 产品规则

普通登录可复用中心会话；未关联或账号不可用时不循环、不自动建号或合并。提供“重新扫码 / 切换账号”以及原账号登录和绑定指引；实际认证方式由中心登记与设备决定，不能保证始终为二维码。用户取消或再次不匹配可返回或重试。工作区邀请、已有密码登录、绑定验证及本地授权继续生效。旧文档、归属、权限、账号映射、MCP 和协作数据保留。

本轮仅 Book Web、普通移动浏览器；不改变中心身份、其他产品或全局会话。自动化和真人验收分开。

## 共同验收与依赖

| ID | 场景与结果 |
|---|---|
| ACC-IDC-SW-001 | 普通登录允许复用有效中心会话；无会话进入中心可用登录方式。 |
| ACC-IDC-SW-002 | 未关联或本地用户不可用时安全拒绝，提供明确恢复入口；不得自动建用户、按邮箱/昵称合并或扩大权限。 |
| ACC-IDC-SW-003 | 用户主动切换账号，创建新事务并要求重新认证；旧中心会话不能直接完成此事务，不全局退出其他产品。 |
| ACC-IDC-SW-004 | 新身份关联且用户可用才建立 Book 会话；仍不匹配时可恢复，不自动重试循环。 |
| ACC-IDC-SW-005 | 过期、取消、重放、篡改、并发标签、中心不可用、旧回调和浏览器会话变化均安全处理；保留草稿与业务数据。 |
| ACC-IDC-SW-006 | 准确区分自动化替身、真实中心、真人微信扫码和线上验收；检查既有关联、成员、文档、权限与现有产品会话。 |
| ACC-IDC-SW-007 | 发布制品可追溯、私有包读取授权最小化、固定版本及 lockfile，回退可操作。 |
