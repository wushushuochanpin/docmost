# 实施与验证计划

1. 只读核对故障时身份匹配及本地用户状态，先区分绑定缺失、账号不可用和其他原因；不记录令牌及敏感 URL。
2. 与中心确认认证核心接口、OIDC 声明与短事务合同，核实私有包发布和本仓库 CI 读取权限。
3. 在隔离环境安装固定 SDK 并完成 NestJS 适配；分阶段替换重复认证逻辑，保留 Book 自有账号映射、会话与权限。
4. 验证普通 SSO、明确重新认证、未关联、再次未关联、不可用、取消/过期、重放、并发标签、在途事务、中心故障、旧密码/绑定、会话及长连接；检验文档和权限不变。
5. 完成构建、依赖来源与发布门禁；按获准范围发布并记录回退。真实扫码、切换账号和既有关联用户验收由用户完成，结果与自动化分开记载。

本文件是计划，不是实施或生产发布记录。
