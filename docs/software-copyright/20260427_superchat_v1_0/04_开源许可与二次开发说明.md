## 二、开源基础说明

本软件基于 Docmost / SuperChat 开源协作文档软件进行二次开发。仓库根目录 `LICENSE` 文件为 GNU Affero General Public License Version 3。仓库 README 中同时说明核心代码使用 AGPL 3.0，企业功能目录另有企业许可。

本次申请材料不纳入以下企业许可目录：

1. `apps/server/src/ee`
2. `apps/client/src/ee`
3. `packages/ee`

本次申请材料覆盖开源许可允许范围内的可运行核心代码及鲜知（北京）科技有限公司组织开发形成的二次开发成果。

## 三、二次开发内容

鲜知（北京）科技有限公司在现有开源基础上组织完成了以下主要改造和功能扩展：

1. SuperChat 品牌与部署配置调整。
2. Docker 部署、Nginx 反向代理和本地绑定安全配置。
3. 工作区备份、备份产物存储和恢复方案相关能力。
4. 页面分享性能优化、分享页面静态渲染和微信分享适配。
5. Mermaid 图表遮罩预览、缩放、拖拽和 PNG/SVG 下载。
6. 页面移动到目标目录的定位弹窗、最近访问、URL 解析和跨空间确认。
7. 侧边栏分类视图、首级目录分类和置顶视图优化。
8. API Key 管理、审计日志和合规管理页面。
9. MCP 只读知识检索接入、权限感知搜索和页面读取服务。
10. 编辑器只读渲染、分享端资源加载、页面树交互和多处用户体验优化。
