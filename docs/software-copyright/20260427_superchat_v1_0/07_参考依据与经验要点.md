# 参考依据与经验要点

**成文日期**：2026-04-27 19:54:02 UTC+8
**最后修订**：2026-04-27 19:54:02 UTC+8

本文档汇总本次软件著作权材料编写参考的官方规则和填表经验。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## 一、官方依据

1. 国家版权局《计算机软件著作权登记办法》
   - 链接：https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/P020241015604759788122.pdf
   - 要点：申请材料包括申请表、鉴别材料和相关证明文件；程序和文档鉴别材料通常由前、后各连续 30 页组成；程序每页不少于 50 行，文档每页不少于 30 行。

2. 国家版权局《计算机软件保护条例》
   - 链接：https://www.ncac.gov.cn/xxfb/flfg/flfg_532/200701/t20070109_50527.html
   - 要点：软件包括计算机程序及其有关文档；软件登记证明文件是登记事项的初步证明；法人软件著作权保护期按条例规定计算。

3. 国家版权局关于软件著作权登记办法修订公告
   - 链接：https://www.ncac.gov.cn/xxfb/tzgg/200303/t20030314_50162.html
   - 要点：软件登记申请材料按一份提交，登记机构审查周期按修订规则执行。

## 二、开源合规依据

1. 最高人民法院知识产权法庭《开源协议适用范围及其对软件著作权侵权判定的影响》
   - 链接：https://ipc.court.gov.cn/zh-cn/news/view-842.html
   - 要点：开源软件并非公共领域软件，开源协议属于附条件的著作权许可；使用、修改和发布开源软件应遵守对应许可证。

2. 本仓库根目录 `LICENSE`
   - 要点：核心开源许可证为 GNU Affero General Public License Version 3。

3. 本仓库 `README.md`
   - 要点：README 中说明 SuperChat core 使用 AGPL 3.0，企业功能目录另有企业许可。

## 三、填表经验依据

1. 阿里云普通软件著作权申请材料在线填写指南
   - 链接：https://help.aliyun.com/zh/copyright-and-patent-service/software-copyright-registration/getting-started/limits-on-information-filling
   - 要点：软件全称、版本号、源程序量、开发环境、运行环境、主要功能、技术特点、代码文档和说明文档应保持一致；代码材料需要与说明文档功能相关联。

2. 常见代理机构与高校办理经验
   - 要点：源代码和说明书页眉的软件名称、版本号应与申请表完全一致；未发表软件不填写首次发表日期；文档材料建议覆盖登录、主界面、主要模块和操作流程。

## 四、本次采用的成熟做法

1. 不纳入 EE 目录，降低企业许可权属解释成本。
2. 申请范围写成“开源核心整体及自有二次开发成果”，避免把原开源软件表述为完全自有原创。
3. 权利取得方式填“原始取得”，开发方式填“独立开发”，软件作品说明建议填“修改”，三者分别对应权利取得、组织开发关系和作品来源。
4. 源程序量按排除 EE 后的源码行数填写为 `97817` 行。
5. 程序鉴别材料采用一般交存，生成前 30 页和后 30 页，每页 50 行。
6. 文档鉴别材料使用软件说明书，覆盖系统环境、架构、功能、流程、权限、安全和部署。
