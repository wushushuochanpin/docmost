源代码鉴别材料说明

成文日期：2026-04-27 19:54:02 UTC+8 最后修订：2026-04-27 19:54:02 UTC+8

本文档说明本次软件著作权源代码鉴别材料的生成范围和规则。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

一、材料范围

本次程序鉴别材料覆盖当前可运行开源核心源码，纳入以下目录：

  1. apps/client/src
  2. apps/server/src
  3. packages/editor-ext/src

排除以下内容：

  1. apps/server/src/ee
  2. apps/client/src/ee
  3. packages/ee
  4. dist 构建产物
  5. node_modules 第三方依赖
  6. 锁文件、配置文件和非源码文档

二、源程序量

按 Git 跟踪源码统计，排除 EE 目录后源程序量为：

97817 行

该数值建议填写到登记系统“源程序量”字段。

三、交存方式

建议选择：

一般交存

生成规则为：

  1. 以 Git 跟踪的源码文件顺序合并程序文本。
  2. 抽取前 30 页源码。
  3. 抽取后 30 页源码。
  4. 每页 50 行。
  5. 页眉标注软件名称、版本号、著作权人和页码。

四、生成文件

generated/SuperChat_知识协作管理系统_V1.0_程序鉴别材料.html

登记系统上传 PDF 文件即可。

五、注意事项

  1. 程序鉴别材料的软件名称必须与申请表一致。
  2. 程序鉴别材料版本号必须与申请表一致。
  3. 不建议将企业许可目录纳入本次程序鉴别材料。
  4. 如登记系统或代理机构要求解释开源基础，请同时上传开源许可与二次开发说明。
