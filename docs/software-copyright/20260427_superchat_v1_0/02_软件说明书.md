# SuperChat 知识协作管理系统 V1.0 软件说明书

## 一、软件概述

SuperChat 知识协作管理系统 V1.0 是面向企业、团队和个人知识库场景的 B/S 架构协作文档软件。系统提供工作区、空间、页面树、在线编辑、实时协作、权限控制、评论、历史版本、全文搜索、附件、外部分享、图表渲染、备份恢复、审计管理、API Key 管理和 MCP 知识检索接入等能力。

系统部署在服务器端，用户通过浏览器访问，无需安装专用客户端。系统支持 Docker 容器化部署，可配合 PostgreSQL、Redis、Nginx 和对象存储服务运行，适用于内网知识库、研发文档中心、项目文档协作、教育科研资料管理和组织内部信息化平台。

## 二、软件目标

1. 为组织提供统一的知识沉淀和文档协作入口。
2. 支持多人实时编辑同一页面，降低文档协同成本。
3. 通过空间、页面树、权限和群组实现内容分区管理。
4. 通过全文搜索、页面历史、评论和附件提升知识检索与协作效率。
5. 通过外部分享、密码与有效期控制支持受控内容分发。
6. 通过备份恢复、审计日志和 API Key 管理提升系统可运维性。
7. 通过 MCP 只读知识检索能力，为 AI 工具安全读取知识库提供接口。

## 三、运行环境

### 3.1 服务器环境

- 操作系统：Linux 发行版，推荐 Ubuntu 22.04/24.04 或同等服务器系统。
- 运行方式：Docker Compose 或 Node.js 生产模式。
- 后端运行环境：Node.js 22。
- 数据库：PostgreSQL 16。
- 缓存与队列：Redis 7.2。
- 反向代理：Nginx 或其他 HTTP 反向代理。
- 存储：本地文件系统，或兼容 S3 协议的对象存储。

### 3.2 客户端环境

- 访问方式：Web 浏览器。
- 支持浏览器：Chrome、Edge、Safari、Firefox 等现代浏览器。
- 终端设备：PC、笔记本电脑、平板电脑或手机浏览器。

## 四、系统架构

系统采用前后端分离的 B/S 架构。前端负责页面渲染、富文本编辑、协作状态展示、权限操作入口、分享页交互和设置管理；后端负责用户认证、权限校验、业务接口、协作服务、数据库读写、文件存储、搜索、备份、审计和 MCP 协议适配。

前端主要技术包括 React、Vite、Mantine、TipTap、Yjs、Socket.IO Client、React Query 和 i18next。后端主要技术包括 NestJS、Fastify、Kysely、PostgreSQL、Redis、BullMQ、Socket.IO、Hocuspocus、对象存储 SDK 和 MCP SDK。编辑器扩展包用于封装表格、附件、视频、嵌入内容、图表、列布局和其他编辑器节点能力。

## 五、主要功能

### 5.1 工作区管理

系统以工作区作为组织级资源边界。首次部署后，管理员通过初始化页面创建第一个工作区和所有者账号。工作区内可以管理成员、空间、页面、权限、设置和系统功能开关。

工作区能力包括：

1. 创建工作区基础信息。
2. 管理工作区成员。
3. 管理工作区级别设置。
4. 配置附件、分享、认证和系统功能。
5. 查看或管理与工作区相关的审计与备份能力。

### 5.2 用户认证

系统支持账号登录、邀请注册、密码重置和登录状态保持。用户登录后，后端颁发身份令牌，前端保存认证状态并在接口请求中携带认证信息。后端根据用户身份、工作区成员关系和权限规则决定是否允许访问资源。

认证能力包括：

1. 邮箱和密码登录。
2. 邀请链接注册。
3. 密码找回和重置。
4. 登录状态校验。
5. 可扩展第三方认证入口。

### 5.3 空间管理

空间用于承载一组相关页面。每个空间可以有独立的成员权限、页面树、分享设置和导航入口。用户可以在不同空间之间切换，查看自己有权限访问的文档集合。

空间能力包括：

1. 创建和维护空间。
2. 设置空间名称和标识。
3. 配置空间成员权限。
4. 管理空间内页面树。
5. 支持跨空间移动页面。

### 5.4 页面树与文档管理

页面是系统中最核心的知识内容载体。页面可以按树形结构组织，支持父子关系、排序、移动、复制、删除和恢复。页面树帮助用户按项目、主题或部门组织知识结构。

页面管理能力包括：

1. 创建普通页面和子页面。
2. 在页面树中展示层级结构。
3. 按父子关系组织文档。
4. 支持页面移动到指定空间或父级目录。
5. 支持最近访问、面包屑和快速定位。
6. 支持页面复制、删除和回收站操作。

### 5.5 目录定位移动

系统提供目录定位移动能力，解决仅靠拖拽难以将页面移动到远距离目录的问题。用户可以在移动弹窗中通过最近访问、URL 粘贴、搜索和权限提示选择目标页面或目标空间。跨空间移动时，系统提示用户确认目标空间变化。

目录定位移动能力包括：

1. 搜索目标页面。
2. 粘贴页面 URL 定位目标。
3. 展示最近访问目标。
4. 支持移动到父级目录末尾。
5. 支持跨空间移动确认。
6. 防止页面移动到自身或后代目录。

### 5.6 侧边栏分类视图

系统在空间侧边栏中提供分类视图，用于降低根节点过多时的浏览成本。分类视图保留真实页面树关系，将“全部”“置顶”和自定义分类作为首级浏览视角，不改变页面本身的父子关系。

侧边栏分类能力包括：

1. 全部视图。
2. 置顶视图。
3. 自定义分类视图。
4. 首级页面分类管理。
5. 与当前页面可见性联动。
6. 与现有页面树、拖拽排序和权限规则兼容。

### 5.7 富文本编辑

系统提供在线富文本编辑能力。用户可以在页面中输入标题、正文、列表、表格、引用、代码块、图片、附件、视频、嵌入内容、数学公式、图表和其他结构化内容。编辑器支持键盘输入、粘贴、快捷操作和工具栏操作。

编辑能力包括：

1. 标题、段落、列表和引用。
2. 加粗、斜体、链接、颜色和高亮。
3. 表格插入、单元格编辑和行列移动。
4. 代码块和语法高亮。
5. 图片、附件、视频和嵌入内容。
6. Mermaid、Draw.io、Excalidraw 等图形内容。
7. 只读渲染和静态渲染。
8. 页面目录和子页面块展示。

### 5.8 实时协作

系统支持多人同时编辑同一页面。协作服务负责同步文档变更、光标状态和编辑内容，避免多人编辑造成内容覆盖。客户端通过协作连接接收变更并实时更新页面。

实时协作能力包括：

1. 多用户共同编辑。
2. 文档状态同步。
3. 协作连接管理。
4. 编辑内容持久化。
5. 异常断线后的恢复。

### 5.9 评论与讨论

用户可以在页面中进行评论和讨论，围绕具体内容提出问题、补充说明或跟进协作事项。评论能力帮助团队在文档上下文中完成异步沟通。

评论能力包括：

1. 页面评论展示。
2. 评论创建和回复。
3. 评论菜单操作。
4. 评论状态管理。
5. 与用户信息和权限联动。

### 5.10 页面历史

系统保存页面历史记录，用户可以查看页面在不同时间的内容变化，辅助追溯误删、误改和协作冲突。页面历史与页面编辑和权限系统配合使用。

页面历史能力包括：

1. 查看页面历史版本。
2. 展示历史内容。
3. 支持历史记录查询。
4. 辅助内容恢复和审计。

### 5.11 全文搜索

系统提供全文搜索能力，帮助用户在工作区或空间范围内查找页面、标题和正文内容。搜索结果根据用户权限过滤，用户只能看到自己有权限访问的内容。

搜索能力包括：

1. 页面标题搜索。
2. 页面正文搜索。
3. 搜索建议。
4. 分享页面搜索。
5. 搜索条件过滤。
6. 权限感知结果返回。

### 5.12 附件管理

用户可以上传和引用附件，将文档、图片、视频或其他文件与页面内容关联。系统根据存储配置将附件保存到本地文件系统或对象存储中，并在页面中展示下载或预览入口。

附件能力包括：

1. 文件上传。
2. 附件引用。
3. 图片展示。
4. 视频展示。
5. 附件下载。
6. 存储驱动适配。

### 5.13 外部分享

系统支持将页面或文件夹以分享链接形式对外发布。分享页面可以使用独立的前端渲染路径，降低主应用资源加载成本。系统可扩展密码、有效期、目录、子页面、微信分享适配等功能。

分享能力包括：

1. 页面分享开关。
2. 分享链接生成。
3. 分享页只读渲染。
4. 分享目录展示。
5. 分享搜索。
6. 微信分享面板与分享元信息。
7. 分享错误和空状态处理。

### 5.14 Mermaid 图表预览

系统支持在代码块中渲染 Mermaid 图表，并提供遮罩预览、缩放、拖拽平移和下载能力。用户可以将图表下载为 SVG 或 PNG 文件，用于文档归档、汇报或二次引用。

Mermaid 能力包括：

1. Mermaid 代码识别。
2. 图表渲染。
3. 单击打开预览。
4. 放大、缩小和拖拽。
5. 触控板手势支持。
6. SVG 和 PNG 下载。

### 5.15 备份恢复

系统提供备份相关接口和页面能力，用于将数据库和存储文件打包为备份产物，并支持下载或上传到对象存储。备份能力提升系统数据安全和运维可控性。

备份能力包括：

1. 手动触发备份。
2. 查询备份任务。
3. 生成备份包。
4. 本地存储备份产物。
5. 可选上传到 S3/COS 对象存储。
6. 备份状态展示。

### 5.16 审计日志

系统提供审计日志能力，用于记录关键操作行为，帮助管理员追踪 API Key、权限、页面、分享、备份等敏感操作。审计能力有助于定位问题和满足组织内部合规管理要求。

审计能力包括：

1. 审计日志列表。
2. 操作主体展示。
3. 操作类型展示。
4. 操作时间展示。
5. 查询和分页。

### 5.17 API Key 管理

系统提供 API Key 管理能力，支持用户或工作区创建访问令牌，并将令牌用于外部系统、自动化工具或 MCP 知识检索服务。API Key 管理与权限、审计和安全提示配合使用。

API Key 能力包括：

1. 创建 API Key。
2. 展示创建后的密钥值。
3. 查看 API Key 列表。
4. 区分用户级和工作区级密钥。
5. 支持权限边界和审计记录。

### 5.18 MCP 知识检索接入

系统提供 MCP 只读知识检索能力，允许外部 AI 工具在授权范围内搜索和读取知识库内容。MCP 网关对现有页面、搜索、权限和附件能力进行适配，不另建平行知识库。

MCP 能力包括：

1. 基于 Bearer API Key 的认证。
2. 只读搜索工具。
3. 页面读取工具。
4. 权限感知结果过滤。
5. 内容格式转换。
6. 附件信息读取。
7. 为 ChatGPT、Cursor、Claude、Codex 等工具提供知识入口。

## 六、权限控制

系统通过工作区成员、空间权限、页面权限和接口守卫控制资源访问。用户访问页面、搜索结果、附件和分享内容时，系统会根据身份和权限返回允许访问的数据。权限设计避免用户读取未授权空间或页面。

权限能力包括：

1. 工作区成员识别。
2. 空间成员权限。
3. 页面访问控制。
4. 接口级权限校验。
5. 搜索结果权限过滤。
6. MCP 查询权限过滤。

## 七、数据存储

系统使用 PostgreSQL 保存用户、工作区、空间、页面、评论、权限、分享、审计、备份任务等结构化数据。Redis 用于缓存、队列和协作相关辅助能力。附件和备份产物保存于本地存储或兼容 S3 的对象存储。

主要数据类型包括：

1. 用户和工作区数据。
2. 空间和页面数据。
3. 页面内容和协作状态。
4. 评论和通知数据。
5. 权限和群组数据。
6. 附件和存储对象。
7. 审计日志和备份任务。

## 八、部署流程

系统支持 Docker Compose 部署。部署人员准备服务器后，复制环境变量示例文件，设置访问地址、应用密钥、数据库密码和存储参数，然后启动服务。系统启动后，访问初始化注册页面创建第一个工作区和管理员账号。

部署步骤如下：

1. 获取软件源代码。
2. 配置 `.env` 环境变量。
3. 设置 `APP_URL`、`APP_SECRET`、数据库密码和存储参数。
4. 执行 `docker compose up -d --build` 启动服务。
5. 通过浏览器访问 `/setup/register`。
6. 创建第一个工作区和管理员账号。
7. 根据需要配置反向代理、HTTPS、对象存储和邮件服务。

## 九、典型使用流程

### 9.1 初始化工作区

管理员首次访问系统时，进入初始化页面，填写工作区名称、管理员账号和密码。系统创建工作区后，管理员进入主界面并开始配置成员、空间和基础设置。

### 9.2 创建空间

管理员或有权限的用户创建空间，填写空间名称和标识。空间创建后，用户可以在该空间中创建页面和子页面，并设置成员访问权限。

### 9.3 创建页面

用户在空间页面树中点击新建页面，输入标题和正文内容。页面创建后，系统保存页面结构，并将页面展示在侧边栏树中。

### 9.4 编辑文档

用户打开页面后，可以输入正文、插入标题、列表、表格、代码块、图片、附件和图表。系统自动同步编辑内容，并在多人协作时展示其他用户的编辑状态。

### 9.5 搜索内容

用户在搜索入口输入关键词，系统返回匹配的页面和内容片段。搜索结果会根据用户权限过滤，只展示用户可访问的内容。

### 9.6 分享页面

用户在页面操作菜单中开启分享，系统生成分享链接。外部访问者通过链接查看只读页面内容。管理员可根据需要设置分享范围、密码或有效期。

### 9.7 使用备份

管理员进入备份相关页面，触发备份任务。系统执行数据库和文件打包，生成备份产物。管理员可下载备份包或将其保存到对象存储中。

### 9.8 接入 MCP

管理员创建 API Key，并将 MCP 服务地址和密钥配置到外部 AI 工具。AI 工具通过 MCP 只读接口搜索和读取授权范围内的知识库内容。

## 十、异常处理

系统在用户未登录、权限不足、页面不存在、搜索无结果、分享失效、备份失败、附件不存在、MCP 入参错误等场景中提供明确的错误处理。前端展示错误页面、空状态或提示信息，后端返回结构化错误响应。

常见异常包括：

1. 用户未登录，跳转到登录页面。
2. 用户权限不足，禁止访问资源。
3. 页面不存在，展示 404 页面。
4. 分享链接失效，展示分享错误状态。
5. 搜索无结果，展示空状态。
6. 备份任务失败，展示失败状态和错误信息。
7. MCP 请求未授权，返回认证错误。

## 十一、安全设计

系统安全设计覆盖认证、授权、输入校验、文件存储、外部分享、API Key 和审计等环节。后端接口通过身份信息和权限规则进行校验，前端只展示用户有权限操作的入口。敏感操作建议记录审计日志。

安全能力包括：

1. 登录认证。
2. 权限校验。
3. API Key 鉴权。
4. 输入数据校验。
5. 分享访问控制。
6. 附件访问控制。
7. 审计日志。
8. 备份产物路径隔离。

## 十二、软件特点总结

SuperChat 知识协作管理系统 V1.0 以在线文档协作为核心，结合空间化知识组织、实时编辑、权限管理、全文搜索、分享发布、备份恢复和 MCP 知识接入能力，形成适合企业和团队自托管部署的知识协作平台。系统采用现代 Web 技术栈和容器化部署方式，便于在云服务器或内网服务器中安装、运维和扩展。
