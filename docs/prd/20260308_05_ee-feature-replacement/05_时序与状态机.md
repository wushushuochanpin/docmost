# 05 时序与状态机

**成文日期**：2026-03-08 23:07:46 UTC+8
**最后修订**：2026-03-08 23:07:46 UTC+8

本文档用于定义时序流程与状态流转规则。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## 时序 1：个人 Token 创建

1. 用户进入 `/settings/account/api-keys`
2. 前端调用 `POST /api/integration-keys/create`
3. 后端校验：
   - 当前用户已登录
   - 工作区策略是否允许当前角色创建 Token
   - Token 名称、过期时间、Scope 是否合法
4. 后端生成随机 Token 明文，计算 hash，写入 `sc_api_tokens`
5. 后端写入 `sc_api_token_events`
6. 后端写入 `sc_audit_events`
7. 后端仅在本次响应中返回明文 Token
8. 前端弹窗提示“只显示一次”

## 时序 2：工作区 Token 管理

1. Admin 进入 `/settings/api-keys`
2. 前端调用 `POST /api/admin/integration-keys/list`
3. 管理员创建或撤销 Token
4. 后端校验 `Admin` 或更高角色
5. 变更写入：
   - `sc_api_tokens`
   - `sc_api_token_events`
   - `sc_audit_events`
6. 列表刷新，展示创建人、所属用户、最后使用时间

## 时序 3：安全策略更新

1. Admin/Owner 进入 `/settings/security`
2. 前端调用 `POST /api/security-policies/get`
3. 用户修改策略后调用 `POST /api/security-policies/update`
4. 后端执行：
   - 权限校验
   - DTO 校验
   - `before/after` 差异生成
   - 更新 `sc_security_policies`
   - 写入 `sc_audit_events`
5. 前端提示保存成功

## 时序 4：OIDC 登录

1. 用户点击自研 SSO 登录入口
2. 系统生成 `state`、`nonce` 并重定向到 IdP
3. IdP 回调到固定回调地址
4. 后端校验：
   - `state`
   - `nonce`
   - issuer
   - 用户映射规则
5. 匹配成功后签发本地 session / JWT
6. 写入登录审计事件
7. 回跳原始页面

## 时序 5：审计日志查询

1. Owner 进入 `/settings/audit`
2. 前端调用 `POST /api/audit-events/list`
3. 后端按 `workspaceId + cursor + filter` 查询
4. 返回：
   - `items`
   - `nextCursor`
   - `hasNextPage`
5. 前端渲染表格与筛选器

## 状态机 1：Token 生命周期

状态：

- `draft`：前端填写中，不入库
- `active`：已创建可使用
- `revoked`：已撤销不可使用
- `expired`：超过有效期不可使用

流转：

- `draft -> active`
- `active -> revoked`
- `active -> expired`
- `expired` 不可回到 `active`
- `revoked` 不可回到 `active`

## 状态机 2：身份提供商生命周期

状态：

- `draft`
- `testing`
- `active`
- `disabled`
- `deleted`

流转：

- `draft -> testing`
- `testing -> active`
- `testing -> draft`
- `active -> disabled`
- `disabled -> active`
- `draft|disabled -> deleted`

## 状态机 3：审计保留期配置

状态：

- `default`
- `customized`

流转：

- 初始化为 `default`
- Owner 保存自定义后进入 `customized`
- 重置为默认值后返回 `default`

## 异常路径

1. Token 创建失败：返回错误码，不生成明文，不写成功审计
2. SSO 测试失败：Provider 保持 `draft` 或 `testing`
3. 审计写入失败：主写链路按能力域决定是否强制失败
4. 保留期更新失败：保持旧值，不触发清理任务
