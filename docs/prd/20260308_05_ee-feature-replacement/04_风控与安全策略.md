# 04 风控与安全策略

**成文日期**：2026-03-08 23:07:46 UTC+8
**最后修订**：2026-03-08 23:07:46 UTC+8

本文档用于定义权限、限流、审计与安全策略。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## 核心原则

1. 合规优先：不输出规避协议的实现建议。
2. 最小权限：所有 Token、策略与 SSO 操作采用最小权限原则。
3. 全链路审计：高风险写操作必须进入审计日志。
4. 代码来源可追溯：每个替代模块必须说明实现来源。

## 合规护栏

### 禁止事项

1. 不允许复制 `apps/client/src/ee/**` 或其样式、页面、接口实现。
2. 不允许从企业版代码做“变量改名式改写”。
3. 不允许把企业版源码交给模型生成后再回贴入仓。
4. 不允许把“接受 AGPL 义务”误表述成“绕开 AGPL”。

### 必须动作

1. 建立 `source_provenance.md` 或同等审计记录。
2. Code Review 增加“来源核查”检查项。
3. 对用到的第三方协议库逐项记录许可证。
4. 在法务未确认前，不将新能力默认归为“可闭源交付”。

## 权限矩阵

| 能力 | Owner | Admin | Member |
| --- | --- | --- | --- |
| 查看个人 Token | 是 | 是 | 是（仅本人） |
| 创建个人 Token | 是 | 是 | 受策略控制 |
| 查看工作区 Token | 是 | 是 | 否 |
| 创建工作区 Token | 是 | 是 | 否 |
| 修改安全策略 | 是 | 是 | 否 |
| 配置 SSO Provider | 是 | 是 | 否 |
| 查看审计日志 | 是 | 可选只读 | 否 |
| 修改审计保留期 | 是 | 否 | 否 |

## Token 风险控制

1. Token 创建后只展示一次明文。
2. 存储时仅保留 `prefix + hash`。
3. 默认启用过期时间，首期建议 90 天。
4. 工作区可开启“仅管理员创建 Token”。
5. Token 作用域必须为预定义枚举，不支持任意自定义字符串。
6. Token 使用失败、超限、撤销后访问都要落审计。

## SSO 风险控制

### OIDC 首期

- 强制 issuer 白名单格式校验
- 回调地址固定模板
- `state` 与 `nonce` 必须校验
- Provider 测试通过后才可启用

### SAML / LDAP 后续

- SAML 证书过期提醒
- LDAP 凭据加密存储
- 测试连接与正式启用分离

## 审计策略

### 审计写入范围

- Token 创建、更新、撤销
- 安全策略修改
- SSO Provider 创建、更新、删除、启用、停用
- 权限相关的高风险配置变更

### 审计字段要求

- `workspaceId`
- `actorId`
- `event`
- `resourceType`
- `resourceId`
- `changes`
- `ipAddress`
- `userAgent`
- `createdAt`

### 审计保留

- 默认 `365` 天
- Owner 可调整
- 清理任务必须先记录清理摘要

## 限流与防滥用

| 接口域 | 默认限流 |
| --- | --- |
| Token 创建 | 每用户每小时 10 次 |
| Token 撤销 | 每用户每分钟 30 次 |
| Provider 测试 | 每工作区每分钟 20 次 |
| 审计查询 | 每用户每分钟 120 次 |

## 数据与密钥安全

1. Provider 密钥与 LDAP 绑定密码必须加密存储。
2. 不在前端本地存储 Token 明文。
3. 审计日志默认不记录敏感字段明文，只记录变更摘要。
4. 严禁把 Token、client secret 写入应用日志。

## 发布前安全门槛

1. 静态扫描通过
2. 来源核查通过
3. 权限越权测试通过
4. Token 泄露与撤销链路测试通过
5. 审计写入与保留期测试通过

## 回滚安全要求

1. 回滚不能删除已产生的审计数据。
2. 回滚时已发出的 Token 必须可统一撤销或冻结。
3. 回滚 SSO 时必须保留本地登录兜底入口。
