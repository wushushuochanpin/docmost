## 2. 背景

上游 docmost 于 2026-05-21 发布 v0.90.0，距我们的上次基线 v0.80.2 跨越一个大版本，包含以下重量级变更：

- **Sidebar tree 完整重写**：删除 `react-arborist`，改为自定义树实现
- **Synced Blocks（引用块）**：新编辑器节点 + 新 DB 表
- **Page Labels / Tags**：新功能，新 DB 表
- **Backlinks（反向链接）**：上游自己做了一版，我们此前也有相关迁移
- **Page break node**：上游加了，我们也有自己的打印预览实现
- **Fixed toolbar 偏好**：新设置项
- **Table 大幅增强**：拖拽排序、表头固定等
- **Azure Blob Storage**：新存储驱动
- **SCIM、Templates、PDF Import**：EE 功能，新文件为主
- **全面 A11y 无障碍修复**：涉及几十个组件

我们自 v0.80.2 以来累积的自定义功能：

| 功能 | 关键文件 |
|---|---|
| 打印预览 + page break + PDF 服务端导出 | `page-editor.tsx`, `extensions.ts`, `Dockerfile` |
| Hocuspocus v4 协作同步现代化 | `persistence.extension.ts`, `collab-app.module.ts` |
| Editor session 租约 / 互踢 | `page-editor.tsx`, `editor-atoms.ts`, `use-editor-session-lease.ts` |
| 侧边栏 category tabs + folder tree UX | `space-tree.tsx`, `global-app-shell.tsx`, `sidebar-atom.ts` |
| 全站深色主题 | `theme.ts`, `app-shell.module.css`, editor CSS |
| 静态分享页 / WeChat 分享 / 分享密码过期 | `share-shell.tsx`, `shared-tree.tsx`, `share.service.ts` |
| 周期备份 / 备份还原 | `core.module.ts`, `database.module.ts`, backup migrations |
| 自托管 token / audit | `page.controller.ts`, `page.service.ts` |
| 401 跳转登录 | `use-auth.ts` |
| Mermaid 预览弹窗 | `extensions.ts`, `editor.module.css` |
| 品牌资产 / 图标替换 | `public/icons/`, `index.html` |

## 3. 冲突分析

### 3.1 双向修改文件总数

共 **112 个文件**两边都有改动，按风险分为四级。

### 3.2 🔴 极高风险文件

#### `apps/client/src/features/editor/page-editor.tsx`

| 维度 | 我们的改动 | 上游改动 |
|---|---|---|
| 规模 | +900 行（session lease、collab 状态、恢复草稿、normalization） | +200 行（transclusion、fixed toolbar、A11y） |
| 核心逻辑 | `useEditorSessionLease`, `pageEditorEditSessionAtom`, collab 状态机 | `TransclusionLookupProvider`, `currentPageEditModeAtom`, link-menu 重构 |
| 冲突模式 | 两边都对文件结构做了大幅重组 |

**解决策略**：以我们版本为基础，cherry-pick 上游的 transclusion provider 包裹、fixed toolbar atom、A11y aria 属性。

#### `apps/client/src/features/page/tree/` (整个目录)

| 维度 | 我们的改动 | 上游改动 |
|---|---|---|
| 基础库 | 基于 react-arborist | **删除 react-arborist，完整重写** |
| 新增功能 | pin/unpin、category tabs、右键菜单增强 | 全新 `doc-tree.tsx`, `doc-tree-row.tsx`, `drop-indicator.tsx`, tree-model 等 |
| 冲突模式 | 架构不兼容，我们的代码基础已不存在 |

**解决策略**：以上游新树为基础，在新实现上重新移植 pin、category tabs 能力。此项工作量最大。

#### `packages/editor-ext/src/lib/page-break/`

| 维度 | 我们的改动 | 上游改动 |
|---|---|---|
| 我们 | 服务于打印预览，含 margin/paper 控制 | 通用 page break 节点，更简洁 |
| 冲突模式 | 同一路径，两套实现思路不同 |

**解决策略**：保留上游 page break 节点作为 schema 基础，在其上叠加我们的打印预览 UI（margin/paper 控制面板）。

#### `apps/server/src/collaboration/extensions/persistence.extension.ts`

| 维度 | 说明 |
|---|---|
| 我们 | Hocuspocus v4 适配，修改了持久化写入逻辑 |
| 上游 | 也有改动（fix collab module） |
| 冲突模式 | 小范围改动，但语义上需要仔细核对 |

**解决策略**：逐行 diff，保留我们的 v4 适配，合入上游的 bugfix。

### 3.3 🟠 中高风险文件

| 文件 | 我们改了什么 | 上游改了什么 | 策略 |

## 6. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| Sidebar tree 移植漏掉细节导致 pin/category 功能缺失 | 高 | 中 | 移植前先在独立文件中实现，单独测试 |
