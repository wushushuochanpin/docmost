# 02 技术方案：架构与接口

**成文日期**：2026-03-04 22:50:29 UTC+8
**最后修订**：2026-03-04 22:51:34 UTC+8

本文档用于定义技术架构、接口契约与兼容策略。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## As-Is 技术现状

1. 匿名公开读取核心入口为 `POST /shares/page-info`，当前主要按 `pageId` 推导 share。
2. 公开页路由同时支持带 `shareId` 与不带 `shareId` 的路径。
3. `shares` 表无密码/过期字段，服务端没有受限访问门禁。
4. 公开搜索 `POST /search/share-search` 未绑定“密码校验通过”上下文。

## To-Be 架构原则

1. 受限分享访问以 `shareId` 为主键边界，不再依赖仅 `pageId` 兜底。
2. 公开读取链路统一前置 `ShareAccessGate` 校验。
3. 密码只做哈希存储与比较，不做明文传递与落日志。
4. 过期判定以服务端当前时间为准。
5. “不记住密码”实现为“无持久化登录态，仅页面生命周期内可用的内存访问令牌”。

## 接口契约（目标）

### 1) 创建分享

`POST /shares/create`

请求体新增字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `pageId` | string | 是 | 页面 ID |
| `includeSubPages` | boolean | 否 | 与现有一致 |
| `searchIndexing` | boolean | 否 | 与现有一致 |
| `accessMode` | `public`\|`password_expiring` | 否 | 默认 `public` |
| `password` | string | 条件必填 | `accessMode=password_expiring` 时必填 |
| `expiresInMinutes` | number | 条件必填 | `1..30`，仅受限模式 |

响应新增字段：

| 字段 | 说明 |
| --- | --- |
| `accessMode` | 分享模式 |
| `expiresAt` | 过期时间 |
| `isExpired` | 是否过期（派生字段） |

### 2) 更新分享

`POST /shares/update`

规则：

1. 保留现有 `includeSubPages/searchIndexing` 更新能力。
2. 不允许通过该接口延长已过期受限链接。
3. 安全敏感字段修改（密码、有效期）统一走“重建链接”接口。

### 3) 重建受限分享（新增）

`POST /shares/regenerate-protected`

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `shareId` | string | 是 | 旧分享 ID |
| `password` | string | 是 | 新密码 |
| `expiresInMinutes` | number | 是 | `1..30` |

行为：

1. 创建新 `share.key`。
2. 旧链接立即失效。
3. 返回新链接和新 `expiresAt`。

### 4) 验证受限访问（新增）

`POST /shares/verify-access`

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `shareId` | string | 是 | 分享 ID/Key |
| `password` | string | 是 | 用户输入密码 |

成功响应：

| 字段 | 说明 |
| --- | --- |
| `accessToken` | 短期访问令牌（仅客户端内存保存） |
| `expiresAt` | 分享到期时间 |

### 5) 公开读取接口收敛

收敛接口：

1. `POST /shares/page-info`
2. `POST /shares/tree`
3. `POST /shares/info`
4. `POST /search/share-search`

统一规则：

1. 请求必须包含 `shareId`。
2. 当 `accessMode=password_expiring` 时必须带有效 `accessToken`。
3. 若 `shareId` 与页面不匹配，返回 `404`（避免泄露存在性）。

## 错误码与状态码约定

| HTTP | code | 语义 | 前端提示 |
| --- | --- | --- | --- |
| 401 | `SHARE_PASSWORD_REQUIRED` | 未提供受限访问凭证 | 请输入密码 |
| 401 | `SHARE_PASSWORD_INVALID` | 密码错误 | 密码错误 |
| 410 | `SHARE_EXPIRED` | 分享链接已过期 | 链接已过期 |
| 404 | `SHARE_NOT_FOUND` | 分享不存在或不匹配 | 链接不存在 |
| 400 | `SHARE_TTL_INVALID` | 有效期非法 | 有效期需在 1-30 分钟 |

## 路由与兼容策略

1. 安全主路径：`/share/:shareId/p/:pageSlug`。
2. 旧路径 `/share/p/:pageSlug` 进入下线流程。
3. 在本期内，若命中旧路径且目标为受限分享，直接返回 404。
4. 公共分享旧路径可短期保留重定向能力（可选开关），下个版本统一移除。

## 前端状态管理约束

1. `accessToken` 仅可保存在内存状态（React state/atom），禁止 localStorage/sessionStorage/cookie 持久化。
2. 页面刷新、关闭、重新打开后，必须重新输入密码。
3. 请求失败依据 `code` 精确提示，不使用模糊“访问失败”。

## 性能与稳定性

1. 密码校验使用 `bcrypt.compare`，并限制单 IP + 单 shareId 的尝试频率。
2. 过期判断在服务端执行，不依赖客户端时间。
3. 门禁校验应在读取页面内容与树之前执行，避免无效重查询。
