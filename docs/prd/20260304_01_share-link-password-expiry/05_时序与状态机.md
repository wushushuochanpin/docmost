## 分享状态机

```mermaid
stateDiagram-v2
    [*] --> Unshared
    Unshared --> PublicActive: 创建普通分享
    Unshared --> ProtectedActive: 创建受限分享
    PublicActive --> Unshared: 删除分享
    ProtectedActive --> ProtectedExpired: reaches expiresAt
    ProtectedActive --> Unshared: 删除分享
    ProtectedActive --> ProtectedActive: 正确密码访问
    ProtectedExpired --> Unshared: 删除旧分享
    ProtectedExpired --> ProtectedActive: 重建新分享(key轮换)
```

## 状态定义

| 状态 | 定义 | 可访问性 |
| --- | --- | --- |
| `Unshared` | 未分享 | 不可匿名访问 |
| `PublicActive` | 普通公开分享生效中 | 可匿名访问 |
| `ProtectedActive` | 受限分享生效中 | 需密码验证 + 未过期 |
| `ProtectedExpired` | 受限分享已过期 | 统一拒绝，提示已过期 |

## 时序 1：创建受限分享

```mermaid
sequenceDiagram
    participant U as 发起人
    participant C as Client
    participant S as Share API
    participant DB as Database

    U->>C: 选择受限分享 + 密码 + 30分钟内有效期
    C->>S: POST /shares/create
    S->>S: 校验权限与参数(1..30)
    S->>S: hash(password)
    S->>DB: insert share(access_mode,password_hash,expires_at)
    DB-->>S: share(id,key,expires_at)
    S-->>C: 返回新分享链接
```

## 时序 2：访问受限分享（成功）

```mermaid
sequenceDiagram
    participant V as 外部访问者
    participant C as Client
    participant S as Share API

    V->>C: 打开 /share/:shareId/p/:pageSlug
    C->>S: POST /shares/page-info (shareId)
    S-->>C: 401 SHARE_PASSWORD_REQUIRED
    V->>C: 输入密码
    C->>S: POST /shares/verify-access (shareId,password)
    S->>S: 校验密码 + 检查过期
    S-->>C: accessToken(短期)
    C->>S: POST /shares/page-info (shareId,accessToken)
    S-->>C: 页面数据
```

## 时序 3：访问受限分享（已过期）

```mermaid
sequenceDiagram
    participant V as 外部访问者
    participant C as Client
    participant S as Share API

    V->>C: 打开过期链接
    C->>S: POST /shares/page-info (shareId)
    S->>S: now >= expiresAt
    S-->>C: 410 SHARE_EXPIRED
    C-->>V: 展示“链接已过期”
```

## 时序 4：重建受限分享

```mermaid
sequenceDiagram
    participant U as 发起人
    participant C as Client
    participant S as Share API
    participant DB as Database

    U->>C: 点击“重新生成链接”
    C->>S: POST /shares/regenerate-protected
    S->>DB: 旧share失效 + 新key写入 + securityVersion++
    DB-->>S: newShare
    S-->>C: 返回新链接
    Note over C,S: 旧链接与旧访问令牌立即失效
```

## 关键状态规则

1. `ProtectedExpired` 是只读终态，不能通过 update 接口恢复。
2. 子页面访问依赖同一 `shareId` 与父分享状态，不能独立续期。
3. 任何令牌验证都必须检查 `securityVersion`，避免重建后旧令牌可用。
