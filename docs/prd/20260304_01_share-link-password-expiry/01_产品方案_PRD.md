## 背景与目标

### 背景问题

1. 当前“分享至网页”是持久公开链接，泄露后缺乏有效止损手段。
2. 当前公开访问链路未提供密码保护与短时失效能力，不满足临时外发场景。
3. 用户核心诉求是“链接到时自动失效，且必须经密码门禁访问”。

### 目标指标（可观测）

1. G1：受限分享在 `expiresAt` 后访问拦截率 = 100%。
2. G2：受限分享密码明文落库事件 = 0。
3. G3：受限分享开启后，通过无 `shareId` 链路访问成功次数 = 0。
4. G4：错误提示命中准确率（密码错误/过期/不存在）>= 99%。

## 现状审计（As-Is）

### 现有页面/交互盘点

1. 分享弹窗仅支持开关公开分享、子页继承、搜索引擎索引。
2. 没有密码输入、有效期选择、过期状态展示。

### 现有接口盘点

1. `POST /shares/create`、`POST /shares/update`、`POST /shares/delete`。
2. 匿名公开读取：`POST /shares/page-info`、`POST /shares/tree`、`POST /shares/info`、`POST /search/share-search`。
3. 公开页路由同时支持 `/share/:shareId/p/:pageSlug` 与 `/share/p/:pageSlug`。

### 现有数据表盘点

1. `shares` 仅有 `includeSubPages`、`searchIndexing` 等字段。
2. 无密码哈希字段、无过期字段、无安全版本字段。

### 现有权限与埋点盘点

1. 分享创建/更新/删除依赖现有 CASL 权限。
2. 缺少受限访问失败（密码错误/过期）的细粒度埋点与审计。

## 目标方案（To-Be）

### 功能总览

1. 新增分享模式：`受限分享（密码 + 失效时间）`。
2. 保留现有模式：`普通公开分享`。
3. 受限分享规则：
- 密码必填。
- 有效期必填，范围 `1-30` 分钟。
- 有效期起点为“创建分享时”。
- 到期后链接不可访问，提示“链接已过期”。
- 到期后不可续期，必须重新生成新链接。
- 不允许浏览器持久化“已验证”状态。
- 子页面继承同一密码与同一过期时间。

### 交互与文案要求

1. 分享弹窗新增“受限分享”选项。
2. 受限分享下展示密码输入与有效期输入（分钟）。
3. 受限分享访问失败文案分三类：
- 密码错误。
- 链接已过期。
- 链接不存在。
4. 产品主文案使用“链接已过期”，避免“密码已过期”造成语义误导。

### 路由与访问边界

1. 安全基线路由：`/share/:shareId/p/:pageSlug`。
2. 无 `shareId` 路由视为高风险兼容路径，逐步下线。
3. 受限分享必须绑定 `shareId` 才可访问。

### 错误码对外契约（产品视角）

1. 用户侧核心可见错误保持三类：
- 密码错误。
- 链接已过期。
- 链接不存在。
2. 技术侧补充错误码用于稳定性与风控：
- 访问令牌无效。
- 有效期参数非法。
- 频控触发。
3. 前端文案与交互必须按 `code` 绑定，不允许按 `message` 模糊判断。

### 路由下线阶段（产品视角）

1. R1（2026-03-05 ~ 2026-03-11）：只观测旧路由流量，不改行为。
2. R2（2026-03-12 ~ 2026-03-18）：受限分享命中旧路由直接拦截。
3. R3（2026-03-19 ~ 2026-03-25）：普通分享旧路由重定向到标准路由。
4. R4（2026-03-26 起）：移除旧路由 `/share/p/:pageSlug`。

## 验收标准

1. ACC-001：创建受限分享时，分钟数 >30 或 <=0 被拒绝。
2. ACC-002：创建成功后返回新链接，且 `expiresAt` 精确可见。
3. ACC-003：正确密码 + 未过期可访问；错误密码返回明确提示。
4. ACC-004：到期后访问返回“链接已过期”，不可查看内容。
5. ACC-005：到期后不能直接续期，必须重新生成新链接。
6. ACC-006：旧链接在重建后立即失效，不可继续访问。
7. ACC-007：子页面在受限模式下继承同一门禁与过期时间。
8. ACC-008：无 `shareId` 路径不能绕过受限分享门禁。
9. ACC-009：错误码与前端文案映射准确，无误判提示。
10. ACC-010：受限分享在旧路由阶段 R2 后不可通过 `/share/p/:pageSlug` 访问。
11. ACC-011：普通分享在 R3 阶段旧路由可重定向，在 R4 阶段完全下线。

## 非目标

1. 不支持按访问者粒度发放不同密码。
2. 不支持超过 30 分钟的受限链接。
3. 不支持“自动续期”或“访问即延长”机制。
