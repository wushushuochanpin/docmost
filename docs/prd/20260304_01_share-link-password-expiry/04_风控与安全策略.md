## 安全控制基线

### 认证与授权

1. 受限分享访问必须通过 `shareId + password` 验证。
2. 验证通过后签发短期 `share_access` 令牌。
3. 令牌必须绑定 `shareId/workspaceId/securityVersion`。
4. 读取接口统一校验令牌与过期状态，失败即拒绝。

### 密码存储与处理

1. 密码哈希使用 `bcrypt`，成本系数与系统账号密码一致。
2. 禁止明文落库、落日志、落埋点。
3. 输入密码仅在验证接口处理，业务接口不接收明文字段。

### 过期控制

1. 受限分享默认硬过期，状态码 `410`。
2. 过期后不可更新有效期，不可恢复旧 key。
3. 重建链接必须旋转 `share.key` 和 `securityVersion`。

### 反暴力破解

1. 对 `verify-access` 施加“IP + shareId”维度限流。
2. 连续失败达到阈值后触发短时冷却。
3. 对高频失败行为输出安全告警日志。

### 信息泄露控制

1. 错误提示按产品要求可区分三类，但接口返回中不暴露页面是否存在等附加信息。
2. `shareId` 与 `pageId` 不匹配返回统一 `404`。
3. 受限分享不输出 SEO 详细元信息。

### 客户端安全约束

1. 访问令牌仅允许内存态保存。
2. 禁止 localStorage/sessionStorage/cookie 持久化访问令牌。
3. 页面刷新后必须重新输入密码。

## 审计与监控

### 关键审计事件

| 事件 | 字段 |
| --- | --- |
| `share_protected_created` | shareId、creatorId、workspaceId、expiresAt |
| `share_access_password_failed` | shareId、workspaceId、ipHash、uaHash |
| `share_access_granted` | shareId、workspaceId、ipHash |
| `share_access_expired_blocked` | shareId、workspaceId |
| `share_regenerated` | oldShareId、newShareId、operatorId |

### 监控指标

1. `verify-access` 失败率。
2. `SHARE_EXPIRED` 命中率。
3. `SHARE_PASSWORD_INVALID` 高频来源 TopN。
4. 受限分享访问 P95 延迟。

## 合规与隐私

1. 密码属于敏感凭据，仅可做单向哈希处理。
2. 审计日志中的 IP/UA 建议脱敏或哈希化。
3. 公开分享属于外发能力，应复用工作区与空间级“禁用公开分享”总开关。
