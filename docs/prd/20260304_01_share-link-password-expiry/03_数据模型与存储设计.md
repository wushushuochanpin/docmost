# 03 数据模型与存储设计

**成文日期**：2026-03-04 22:50:29 UTC+8
**最后修订**：2026-03-04 22:51:34 UTC+8

本文档用于定义核心实体、字段与存储策略。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## 设计目标

1. 在不拆分 `shares` 领域模型的前提下，支持受限分享。
2. 防止明文密码入库。
3. 支持“过期后不可续期、必须重建”策略。
4. 支持受限访问令牌失效控制。

## 数据模型变更（`shares` 表扩展）

| 字段 | 类型 | 空值 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `access_mode` | varchar(32) | 否 | `public` | 分享模式：`public` / `password_expiring` |
| `password_hash` | varchar(255) | 是 | null | 受限模式密码哈希（bcrypt） |
| `expires_at` | timestamptz | 是 | null | 受限模式过期时间 |
| `security_version` | integer | 否 | 1 | 安全版本号，重建后自增用于令牌失效 |
| `expired_at` | timestamptz | 是 | null | 首次判定过期时间（可审计） |

## 约束规则

1. `access_mode='public'` 时：`password_hash`、`expires_at` 需为 null。
2. `access_mode='password_expiring'` 时：`password_hash`、`expires_at` 必须非 null。
3. `expires_at` 必须由后端按 `now + expiresInMinutes` 计算。
4. `expiresInMinutes` 输入范围强校验为 `1..30`。
5. 分享重建后必须更换 `key` 并 `security_version = security_version + 1`。

## 索引与查询优化

| 索引 | 类型 | 目的 |
| --- | --- | --- |
| `shares_key_workspace_id_unique` | 已有唯一约束 | 分享链接唯一性 |
| `idx_shares_expires_at` | 普通索引 | 加速过期清理与统计 |
| `idx_shares_access_mode_expires_at` | 复合索引 | 加速受限分享过期查询 |

## 迁移策略

### 正向迁移

1. 新增字段与约束，默认全部存量记录 `access_mode='public'`。
2. 存量分享无需回填密码与过期字段。
3. 更新 `db.d.ts` 与实体类型定义。

### 回滚迁移

1. 若功能回滚，先停止新写入受限模式。
2. 保留新增字段不立即删除，防止历史数据丢失。
3. 完全回滚时再执行删字段迁移（仅在确认无受限记录后）。

## 令牌与存储策略

1. 不新增独立会话表，受限访问令牌使用签名 JWT（短生命周期）。
2. 令牌载荷包含 `shareId`、`workspaceId`、`securityVersion`、`type=share_access`。
3. 读取接口校验 `securityVersion`，确保重建链接后旧令牌失效。

## 数据治理与生命周期

1. 过期分享不立即物理删除，保留以支持“已过期”精确提示与审计。
2. 可选异步任务：清理 `expired_at` 超过 N 天的受限分享记录（默认 N=30）。
3. 审计日志保留策略复用现有日志保留规则。
