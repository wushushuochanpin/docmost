## 权限策略

- 继续复用 Space 权限模型。
- 只读用户：仅可查看置顶徽标与节点统计，不可触发写操作。
- 可编辑用户：保留原有创建、重命名、移动、置顶操作能力。
- 统计字段权限：与 `POST /pages/sidebar-pages` 读权限一致，不新增单独权限点。

## 风险点与控制

- 风险 R1：样式改造导致点击热区错位。
  - 控制：保持操作区节点结构不变，仅调整显示方式；行点击与箭头点击分离验收。
- 风险 R2：统计误导（口径不一致）。
  - 控制：统一定义 `directChildFolderCount` 与 `descendantTotalCount`；抽样 SQL 对账。
- 风险 R3：图标语义冲突。
  - 控制：置顶标识与类型标识组合展示，避免单一图标歧义。
- 风险 R4：深层目录聚合导致接口延迟上升。
  - 控制：灰度期重点监控 `API-001` P95；超阈值优先回滚聚合字段逻辑。
