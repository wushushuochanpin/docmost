## 接口契约（API）

### 复用接口（路径不变）

- API-001：`POST /pages/sidebar-pages`
  - 用途：获取目录子节点（含 `nodeType`, `isPinned`, `pinnedAt`）并返回侧边树统计字段。
  - 请求字段：无变化。
  - 响应字段新增（向后兼容）：
    - `directChildFolderCount: number`：当前节点一级下级目录数（仅 `depth=1 && nodeType=folder`）。
    - `descendantFolderCount: number`：当前节点全部下级中的文件夹总数（`depth>=1`）。
    - `descendantFileCount: number`：当前节点全部下级中的文件总数（`depth>=1`）。
    - `descendantTotalCount: number`：`descendantFolderCount + descendantFileCount`。
  - 兼容策略：旧前端可忽略新增字段，新前端在字段缺失时进入降级显示逻辑。

### 无新增接口说明

- 本期不新增 API 路径，不改动权限接口，不改动 pin/unpin 协议。
- 本期允许 API-001 在同一路径下扩展响应字段（兼容新增）。

## 前端渲染设计

### 置顶标识

- 在 `SpaceTree` 节点行新增 `pinnedBadge` 徽标：
  - 包含 `pin` 图标（状态）与 `file/folder` 图标（类型）。
  - 作用：避免用户仅靠排序判断置顶状态。

### 侧边树交互与行业成熟方案细化（参考飞书/同类知识库）

- 节点布局改为固定 flex 语义：
  - 名称区域 `flex: 1`。
  - 统计区域固定槽位（建议最小宽度 72px，右对齐）避免跳动。
  - 操作区常驻占位、hover/selected 时显隐，防止布局抖动。
- 点击行为定稿：
  - 行点击（folder）：同一次交互触发“展开并进入页面”。
  - 行点击（file）：进入页面，不触发展开。
  - 箭头点击：仅展开/收起，不触发跳转。
- 动效与状态（行业常见做法）：
  - hover/selected/open 三态底色有层级区分，不覆盖可读性。
  - 统计值变化与展开状态变化使用轻量过渡动画（<=120ms）。
  - 数值超大时用 `999+`，完整值通过 tooltip 展示。
- 计数展示规则：
  - 每个节点显示 `directChildFolderCount · descendantTotalCount`。
  - 文件节点按 `0 · 0` 展示（与“每个节点都显示”保持一致）。
- 硬性保留：
  - 三点（更多菜单）、加号（新建按钮）按设计稿保留。
  - 左侧树区域自定义宽度（`global-app-shell` 侧边栏拖拽调整）不得移除或失效。
- 实现偏好：
  - 优先使用现有依赖库（Mantine、项目内组件或成熟 npm 库）实现，尽量不从零手写。

### 目录统计

- `FolderView` 顶部统计由 `items` 改为：`{folderCount} folders · {fileCount} files`。
- 计数规则：仅统计当前目录直接子节点。

### 文档编排按钮置顶

- 在页面编辑区内容顶部增加吸顶格式化工具栏（或复用 BubbleMenu 能力输出一套固定工具栏）：加粗、斜体、下划线、删除线、行内代码、标题 H1/H2/H3、列表、对齐、链接、图片、表格、引用等。
- 实现方式：采用 `position: sticky` 容器，工具栏与 BubbleMenu 并存。
- 约束细节：
  - 建议 `top` 对齐全局 header 下沿，避免遮挡正文首行。
  - 工具栏 `z-index` 低于全局弹窗、高于正文内容。
  - 小屏下采用横向滚动工具栏，不移除既有格式化能力。

## 兼容性策略

- 若后端返回 `nodeType` 缺失，沿用既有兜底逻辑视为 `file`。
- 若统计字段缺失：
  - `directChildFolderCount`：可由已加载直接子节点临时计算。
  - `descendantTotalCount`：降级为 `0` 并加 `data-fallback` 标识用于排查。
- 未知 `nodeType` 按 `file` 处理，避免页面崩溃。

## 回归点

- 树节点点击路径：folder 行点击是否“展开+进入页面”联动；箭头点击是否仅展开/收起。
- 操作按钮显隐是否影响拖拽与重命名。
- 节点统计是否符合口径：一级目录数、全部下级总数。
- API-001 响应耗时是否可控（灰度期重点观察 P95）。
- 编辑器吸顶工具栏：滚动后仍可见、快捷键保持一致、移动端/小屏不遮挡内容。
