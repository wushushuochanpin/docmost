## 状态机：树节点操作区显隐

- `idle`：操作区透明占位（不可点击）。
- `hover`：操作区显示并可交互。
- `selected`：操作区保持显示并可交互。
- `editing`：进入重命名输入状态，图标与输入框保持同线对齐。

状态迁移：

- `idle -> hover`：鼠标进入节点。
- `hover -> idle`：鼠标离开且未选中。
- `hover -> selected`：点击节点。
- `selected -> editing`：触发重命名。
- `editing -> selected`：提交或取消重命名。
