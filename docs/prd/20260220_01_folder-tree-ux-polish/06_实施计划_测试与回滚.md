## 实施计划

1. 开发阶段：完成 `SpaceTree`/`FolderView` 渲染与样式改造，以及页面编辑器「文档编排按钮置顶」吸顶工具栏。
2. 自测阶段：执行 TS 编译、关键交互走查。
3. 联调阶段：在测试 workspace 验证目录数据、置顶状态、对齐效果及编辑器吸顶工具栏滚动与编排功能。
4. 发布阶段：按 workspace 小流量灰度发布。

## 发布与灰度

- 发布方式：前端常规发布。
- 灰度策略：测试 workspace -> 10% 生产 workspace -> 全量。
- 灰度观察指标：
  - 页面渲染报错率。
  - 树节点点击与重命名成功率。
  - 目录统计显示正确率（抽样检查）。
  - 编辑器吸顶工具栏展示与编排操作成功率。

## 回滚方案

- 触发条件：
  - 关键交互失效（无法点击节点/无法操作菜单、编排按钮失效）。
  - 样式严重错位影响可用性。
  - 统计数与实际列表明显不一致。
- 回滚步骤：
  1. 回退本次前端提交（`SpaceTree`、`FolderView` 及编辑器相关改动文件）。
  2. 重新构建并发布。
  3. 验证核心页面恢复。
- 回滚目标时长：30 分钟内。
