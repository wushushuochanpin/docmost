## 产品确认结果（已确认）

以下为产品已确认的结论，实施时须严格遵守。

1. **侧边树（设计稿引入 + 必须保留）**  
   - **从设计稿引入**：点击展开/折叠、底色动态效果、数量展示；三点（更多菜单）与加号（新建按钮）**设计稿已更新并包含**，实现时与设计稿一致即可。  
   - **必须保留**：左侧树区域自定义宽度（用户可拖拽调整侧边栏宽度），不得因本次改造而移除或失效。

2. **目录页 D3**  
   - 仅做展示增强（不改变列表、筛选、权限逻辑）；文案格式以设计稿为准（如「X folders · Y files」或「文件夹数 · 文件数」）。

3. **页面编辑器 D4**  
   - 吸顶工具栏与现有 BubbleMenu **并存**，不二选一。

## 现有功能不删减检查清单

施工前后均需确认以下行为未被移除或弱化：

- **侧边树**：**左侧树区域自定义宽度（拖拽调整侧边栏宽度）必须保留**；节点点击进入页面、三点（更多菜单）与加号（新建）保留（设计稿已包含）；右键/更多菜单、新建/重命名/拖拽、置顶排序规则、无权限时的展示与提示；引入设计稿的展开/折叠、底色动态、数量展示时不得移除上述入口。
- **目录页**：列表加载与分页、排序与筛选、进入子页/编辑入口、空态与无权限提示。
- **页面编辑器**：加粗/斜体/下划线/删除线/行内代码、标题 H1/H2/H3、有序与无序列表、对齐、链接/图片/表格/引用等编排能力，以及现有快捷键与选中态 BubbleMenu；吸顶栏与 BubbleMenu 并存，两者均保留。
- **通用**：现有埋点与权限逻辑、接口契约（本期无新增/变更接口）。
