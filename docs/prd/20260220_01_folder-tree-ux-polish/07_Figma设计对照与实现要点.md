## 产品确认结果（已确认）

以下结论已确认，实施时必须严格遵守：

1. 侧边树行点击行为：点击 folder 节点时同时触发展开与进入页面；点击文件节点保持进入页面；箭头点击仅展开/收起。
2. 节点统计口径：每个节点展示“一级下级目录数 + 全部下级（文件夹+文件）总数”。
3. 参考行业成熟方案（飞书/同类知识库）补充细节：信息层级、统计视觉权重、交互动效与异常降级按本文件“行业细节”执行。
4. 测试与回归细化：按 06 中扩展后的测试矩阵逐项验证，不可仅做“无退化”笼统检查。
5. 评审建议采纳：允许 `API-001` 扩展兼容字段，不新增接口路径；灰度期间增加性能观测与回滚分层。
6. 删除无关文档：本 PRD 包内与本专题无关的流程图文件移除。

## 行业成熟方案细化（参考飞书等）

- 交互优先级：
  - 行点击为主路径，保证最快到达目标页面。
  - 箭头作为次路径，仅服务于结构浏览。
- 视觉层级：
  - 文档标题为第一层信息。
  - 统计值为第二层信息，使用弱化色而非主文本色。
  - 操作区（更多/新建）只在 hover/selected 强化显示。
- 稳定性细节：
  - 统计区域固定宽度，避免数字变化引发布局抖动。
  - 大数字使用 `999+`，完整值在 tooltip 显示。
  - 统计字段缺失时使用降级样式并保留可追踪标记。
- 无障碍与可用性：
  - 可交互区域需有明确 hover/focus 反馈。
  - 键盘导航与屏幕阅读器语义不因本次改造退化。

## 现有功能不删减检查清单

施工前后均需确认以下行为未被移除或弱化：

- 侧边树：左侧树区域自定义宽度（拖拽调整侧边栏宽度）必须保留；节点点击进入页面、箭头展开/收起、三点（更多菜单）与加号（新建）保留；右键/更多菜单、新建/重命名/拖拽、置顶排序规则、无权限展示与提示保留。
- 目录页：列表加载与分页、排序与筛选、进入子页/编辑入口、空态与无权限提示保留。
- 页面编辑器：加粗/斜体/下划线/删除线/行内代码、标题 H1/H2/H3、有序与无序列表、对齐、链接/图片/表格/引用等编排能力保留；吸顶栏与 BubbleMenu 并存，两者均保留。
- 通用：现有埋点与权限逻辑保留；接口路径不变（`POST /pages/sidebar-pages`），仅允许响应新增兼容字段。

## 实现原则（技术约束）

- 优先使用现有依赖库：能通过现有依赖（Mantine、项目内组件或成熟 npm 库）实现的，优先直接引用或封装，避免从零手写。
- 先保功能再调视觉：任何视觉/动效变更不得影响导航、编辑、拖拽、权限与快捷键行为。
- 可回滚优先：前端改造与接口字段扩展均需独立可回退。
