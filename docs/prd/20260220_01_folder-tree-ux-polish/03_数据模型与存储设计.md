## 数据模型结论

- 本期不新增数据表、不新增字段、不改动索引。
- 复用字段：
  - `pages`（目录关系）
  - `page_node_meta.node_type`
  - `page_node_meta.is_pinned`
  - `page_node_meta.pinned_at`

## 计数口径

- 统计对象：当前目录直接子节点。
- 计算方式：前端收到 `sidebar-pages` 数据后按 `nodeType` 本地聚合。
- 不在数据库侧新增聚合查询，避免额外成本。

## 迁移与回滚

- 数据迁移：无。
- 回滚策略：无数据回滚动作，仅回退前端逻辑。

## 数据一致性风险

- 风险：`nodeType` 缺失导致计数偏差。
- 缓解：客户端 fallback 为 `file` 并保留总量校验。
