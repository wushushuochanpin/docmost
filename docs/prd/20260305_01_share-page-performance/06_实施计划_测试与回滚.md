## 回归范围

1. 分享页全链路：ShareRedirect、SharedPage、密码门禁、错误态、多页树、TOC、ShareSearchSpotlight、主题切换。
2. 只读编辑器：标题、正文、表格、代码块、图片、链接、Callout 等展示与现有 mainExtensions 行为一致（仅扩展子集不同，不破坏已支持内容类型）。
3. 与 share-link-password-expiry 的配合：受限分享创建、验证、过期、重建后访问均无回归。

## 回滚方案

1. **前端回滚**：通过发布系统回滚至上一版本；skeleton、只读扩展、按需加载均为前端开关或代码回退，无数据迁移。
2. **后端回滚**：若本期实现合并接口，保留现有 page-info / tree 接口，前端可配置或 fallback 回多请求模式；回滚时关闭新接口或前端切回旧请求方式即可。
3. **回滚触发**：首屏错误率上升、TTI 劣化、或功能回归导致分享不可用，触发回滚并复盘。

## 成功指标复述

- G1：移动端分享页 TTI P75 较优化前下降 ≥ 30%。
- G2：1s 内出现 skeleton 或首屏内容。
- G3：分享页功能与权限与优化前一致，回归用例通过。
