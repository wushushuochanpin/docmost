## 回归范围

1. 分享页全链路：ShareRedirect、SharedPage、密码门禁、错误态、多页树、TOC、ShareSearchSpotlight、Reader 主题样式。
2. 静态 HTML 主渲染：标题、正文、表格、代码块、图片、链接、Callout、Details、附件等展示与现有语义一致。
3. 重内容降级链路：Drawio、Excalidraw、Embed、Mention、媒体块等在“占位 -> 完整加载”过程中无功能性损坏。
4. Reader Contract：代码块纯展示、`Mermaid` 源码降级、无手动主题切换的分享页样式与行为符合定义。
5. 安全边界：HTML 清洗、URL allowlist、embed allowlist、权限回退均通过。
6. 与 `share-link-password-expiry` 的配合：受限分享创建、验证、过期、重建后访问均无回归。

## 灰度建议

1. 保持 share 独立入口开关，同时新增静态 renderer 开关，仅对 `/share/*` 正文渲染路径生效。
2. 灰度顺序建议：
   - 内部环境
   - 小流量 workspace / 指定 shareId 白名单
   - 10% / 30% / 100%
3. 观测指标至少包含：
   - skeleton 可见时间
   - 首个正文可读时间
   - 基础 JS gzip 包体
   - `renderMode=static-html` 命中率
   - renderer fallback 率
   - share route 请求失败率
   - HTML 清洗异常率

## 回滚方案

1. **前端回滚**
   - 通过静态 renderer 开关，将正文路径切回 legacy `ReadonlyPageEditor`
   - HTML 容器、hydrator 与 TOC-from-DOM 均可整体关闭
2. **分享独立入口回滚**
   - 若 share entry 出现问题，直接将 `/share/*` 回切到原主站路由实现
   - 主站其他路由无需回滚
3. **后端回滚**
   - 保留现有 `page-info / tree / info` 旧语义
   - `page-info` 可停止返回 `rendered`
   - 前端 fallback 到旧请求与旧正文渲染模式
4. **回滚触发**
   - 首屏错误率上升
   - 首个正文可读时间显著劣化
   - 分享页出现无法阅读、正文缺失、XSS、危险跳转、密码门禁失效等 P1 缺陷

## 成功指标复述

- G1：Skeleton 可见时间 `<= 1s`
- G2：首个正文可读时间 P75 较优化前下降 `>= 40%`
- G3：分享阅读路径基础 JS gzip 不高于 `300 KB`
- G4：正文首屏阻塞请求数显著下降
- G5：静态 HTML 命中率 `>= 95%`
- G6：分享页功能与权限与优化前一致，回归用例通过
