## 架构总览

**前端新增 UI，后端做向后兼容增强。**

- 前端新增：
  - `MoveToModal` 主弹窗组件
  - `MoveTargetItem` 列表项组件
  - `use-recent-pages` hook（localStorage 最近访问管理）
  - `use-move-to` hook（弹窗业务逻辑）
- 前端修改：
  - `page-header-menu.tsx`：新增"Move to..."入口
  - `space-tree.tsx`：右键菜单新增"Move to..."入口
  - `page-service.ts`：封装前端可用的 `movePage` 函数
  - `page.tsx`（路由页面）：页面挂载时写入最近访问记录
- 后端修改：
  - `MovePageDto.position` 允许省略 / `null`
  - `PageService.movePage()` 在 `position` 缺省时生成目标子树末尾 position
  - `PageService.movePage()` 增加自身 / 后代 cycle guard

### 不变边界

- 不新增后端接口
- 不破坏 `POST /pages/move` 旧请求结构，旧客户端继续传字符串 position
- 不修改现有拖拽逻辑（`use-tree-mutation.ts`）
- 不修改旧 `MovePageModal`（跨 Space 快速入口保留）

## 接口契约（复用现有接口）

### 1. 搜索建议 + 结果富化

```
POST /search/suggest
Request: {
  query: string,
  includePages: true,
  limit: 8
}
Response: {
  pages: Array<Partial<IPage>>
}
```

- 现状 `pages` 仅保证 `id / slugId / title / icon / spaceId`。
- P0 前端对最多 8 条结果并发调用 `POST /pages/info { pageId: slugId, includeContent: false }`，补齐 `nodeType / space.name / space.slug / permissions.canEdit`。
- P0 阶段 `parentPath` 暂只显示 Space 名称，不展示多级祖先路径。

### 2. 页面信息查询（URL 解析与目标富化）

```
POST /pages/info
Request: {
  pageId: string,          // UUID 或 slugId
  includeContent: false
}
Response: IPage（含 spaceId, nodeType, title, id 等）
```

- 解析成功后构造 `MoveTargetPage` 并直接设为 `targetPage`。
- 解析失败（404）：展示 `urlError = "Page not found"`。

### 3. 同 Space 移动

```
POST /pages/move
Request: {
  pageId: string,
  parentPageId: string | null,
  position?: string | null // null / 缺省时追加到目标末尾
}
```

- 前端封装为：
```typescript
export async function movePage(dto: {
  pageId: string;
  parentPageId: string | null;
}): Promise<void>
```

### 4. 跨 Space 移动序列

```
Step 1: POST /pages/move-to-space
Request: { pageId, spaceId: targetSpaceId }

Step 2: POST /pages/move
Request: { pageId, parentPageId: targetPageId, position: null }
```

- 两步均成功后再更新 UI。
- 若 Step 1 成功、Step 2 失败，页面已在目标 Space 根级；前端提示用户页面已移动到目标 Space 但未设置父级位置，并跳转目标 Space 页面 URL。

### 5. `POST /pages/move` 后端兼容增强

| 字段 | 现状 | To-Be | 兼容策略 |
|---|---|---|---|
| `position` | 必填字符串 | 可选；`null` / 缺省表示追加到目标父级末尾 | 旧拖拽仍传字符串，不受影响 |
| cycle guard | 单页 move 未覆盖自身/后代 | 服务端递归检查目标父级祖先链包含被移页面则 400 | 所有入口受益 |

## 缓存更新策略

移动成功后，调用现有 `updateCacheOnMovePage` 或直接失效相关 queryKey：

```typescript
// 同 Space 移动
queryClient.removeQueries({
  predicate: (item) =>
    ["sidebar-pages", "root-sidebar-pages"].includes(item.queryKey[0] as string),
});
setTreeData([]);

// 跨 Space 移动（范围更大）
queryClient.removeQueries({
  predicate: (item) =>
    ["pages", "sidebar-pages", "root-sidebar-pages"].includes(item.queryKey[0] as string),
});
```

## 路由与导航

| 移动类型 | 移动后行为 |
|---|---|
| 同 Space 同父级（位置调整） | 路由不变，树刷新 |
| 同 Space 不同父级 | 路由不变，树刷新 |
| 跨 Space | `navigate(buildPageUrl(targetSpaceSlug, slugId))` 跳转到新 URL |
