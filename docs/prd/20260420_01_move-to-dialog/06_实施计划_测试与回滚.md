## 灰度策略

本期为纯前端功能，无后端变更，灰度风险极低：

1. **开发环境**：完整 E2E 测试所有 TC。
2. **staging 环境**：小范围用户试用，收集反馈。
3. **生产全量**：staging 通过后直接全量，无需 feature flag。

---

## 回滚策略

| 触发条件 | 回滚动作 | 目标时长 |
|---|---|---|
| MoveToModal 导致崩溃 | 移除两处入口（page-header-menu + space-tree 的"Move to..."菜单项），不影响其他功能 | 5 分钟（改两行代码 + 部署） |
| 最近访问写入导致 localStorage 异常 | 在 `recordRecentPage` 中加 try-catch，静默失败 | 1 分钟（热修复） |
| 移动 API 调用出现大量 500 | 后端接口已有的回滚策略，前端透传 error | N/A（后端已有） |

**回滚不会**影响：
- 现有拖拽移动
- 旧 MovePageModal
- 批量移动
- 所有页面数据（仅改前端组件）
