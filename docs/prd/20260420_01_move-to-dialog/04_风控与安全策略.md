本文档用于定义校验规则、权限守护与异常处理策略。**阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。**

## 前端校验规则

| rule_id | 触发时机 | 校验内容 | 前端表现 | 后端兜底 |
|---|---|---|---|---|
| FE-001 | 渲染列表项时 | 目标 `pageId === currentMovingPageId` | 列表项禁用，Tooltip:"Cannot move to itself" | 后端 `movePage` 校验 |
| FE-002 | 渲染列表项时 | 目标是被移页面的已知后代 | 列表项禁用，Tooltip:"Cannot move into a child page" | 后端递归祖先检查 |
| FE-003 | 渲染列表项时 | 被移项为 `folder`，目标为 `file` | 列表项禁用，Tooltip:"Folders can only go inside folders" | 后端层级规则校验 |
| FE-004 | 渲染列表项时 | 用户对目标页面无编辑权（`canEdit = false`） | 列表项灰色禁用，Tooltip:"No edit access" | 后端权限校验 |
| FE-005 | URL 解析时 | 粘贴内容不匹配页面 URL 格式 | 输入框下方红色提示:"Invalid page URL" | — |
| FE-006 | URL 解析时 | slugId 对应页面 API 返回 404 | 提示:"Page not found" | — |
| FE-007 | 点击 Move Here 前 | `targetPage === null` | Move Here 按钮禁用（灰色） | — |

## 后端权限守护

本期不新增后端接口，依赖现有守护：

| 接口 | 守护层 | 校验内容 |
|---|---|---|
| `POST /pages/move` | `PageGuard` + `PageService.movePage()` | 被移页面编辑权；目标父级编辑权；层级规则；自身/后代 cycle guard；position 自动追加 |
| `POST /pages/move-to-space` | `PageGuard` + `PageService.movePageToSpace()` | 被移页面编辑权；目标 Space 成员权限 |
| `POST /pages/info` | `PageGuard` | 读权限（无读权限则 404/403，用于 URL 解析失败场景） |
| `POST /search/suggest` | Auth Guard | 已登录用户，仅返回有读权限的页面 |

## 误操作防护

| 场景 | 防护措施 |
|---|---|
| 跨 Space 移动（不可逆性高） | 在 Modal 内切换到确认视图，明确展示"将移动到 {{spaceName}} Space"并要求二次点击 Confirm |
| 误选目标后直接点 Move Here | 选中预览区醒目展示目标信息（Space + 路径面包屑），用户可在点击前审查 |
| 移动导致页面从当前侧边树视图消失 | 移动成功后统一刷新侧边树，同 Space 时路由不变，用户可在新位置找到页面 |
| 快速重复点击 Move Here | `isLoading` 为 true 时 Move Here 按钮禁用，防止重复提交 |

## 异常处理矩阵

| 场景 | HTTP 状态 | 前端行为 |
|---|---|---|
| 后端权限校验失败 | 403 | Notification: "You don't have permission to move this page" |
| 目标是自身后代 | 400 | Notification: "Cannot move a page into its own child" |
| 层级规则违反 | 400 | Notification: 后端 message 直接展示 |
| 目标页面已删除 | 404 | Notification: "Target page no longer exists"；清空 targetPage |
| 网络超时 | 503/timeout | Notification: "Move failed. Please try again." |
| 跨 Space 移动第一步成功第二步失败 | 400/500 | Notification: "Moved to space but failed to set location. Page is now at root of {{spaceName}}." |

## localStorage 安全考量

- localStorage 内容仅记录已访问页面的元数据（标题、icon、nodeType 等），不含内容。
- 恶意构造 localStorage 不影响后端安全，后端权限校验为最终守卫。
- XSS 防护：已有的 CSP 和 Mantine 渲染层不直接 innerHTML 用户数据，`title` 通过 React 文本节点渲染，无 XSS 风险。
