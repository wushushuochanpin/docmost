## 现有"移动"能力盘点

### 1. 侧边栏拖拽（`space-tree.tsx` + `use-tree-mutation.ts`）

- 用户可在侧边栏通过拖拽调整页面的父子关系和排序。
- 实现库：`react-arborist`。
- 移动后：前端乐观更新树状态，再向后端发送 WebSocket 消息，并调用 `POST /pages/move`。
- 已有的校验：
  - 不允许多选拖拽
  - 根级只允许文件夹
  - 文件可承载文件子节点，但文件夹不能放入文件
  - 移动到父级时清空 `sidebarCategoryId`
- **缺陷**：当目标节点在视口之外、层级很深、跨 Space 时，拖拽操作极不友好。

### 2. 页面顶部菜单 "Move"（`page-header-menu.tsx`，第 312 行）

- 点击后打开 `MovePageModal`。
- `MovePageModal` 只展示 Space 选择器（`SpaceSelect`），调用 `POST /pages/move-to-space`。
- **缺陷**：无法在移动到 Space 后指定目标父级；无法在同一 Space 内将页面移到指定文件夹。

### 3. 批量移动（`space-tree.tsx`，第 1055–1121 行）

- 通过多选模式选中若干节点，点击"Move filtered pages here"/"Move selected here"。
- 调用 `POST /pages/batch-move`，目标为当前已展开的某个文件夹。
- **缺陷**：依赖在侧边树中先定位到目标文件夹，再从右键菜单触发，操作路径较长。

## 后端接口现状

| 接口 | 方法 | 位置 | 现状 |
|---|---|---|---|
| `POST /pages/move` | 同 Space 内移动 | `page.controller.ts:761` | 已实现，支持 `pageId + parentPageId + position`；现状 `position` 必填字符串，不支持 `null` 自动追加 |
| `POST /pages/move-to-space` | 跨 Space 移动 | `page.controller.ts:619` | 已实现，支持 `pageId + spaceId` |
| `POST /pages/batch-move` | 批量移动 | `page.controller.ts:799` | 已实现 |
| `POST /pages/info` | 按 `pageId` 查询页面 | `page.controller.ts:77` | 已实现，`pageId` 可传 UUID 或 slugId，可用于 URL 解析 |
| `POST /search/suggest` | 搜索建议 | `search.controller.ts` | 已实现，支持 `includePages: true`；现状结果缺少 `nodeType / space / canEdit`，需前端二次查询补齐 |

**结论：主体移动接口已具备，但并非所有必要能力都完全就绪。本期需要前端新增 UI，同时对 `POST /pages/move` 做向后兼容扩展：允许 `position` 缺省 / `null` 自动追加，并补充移动到自身或后代的后端阻断。**

## 最近访问状态现状

- 系统已有 `POST /pages/recent` 最近更新列表，但它按 `updatedAt` 排序，不等于用户最近打开的文档。
- 系统无"最近打开页面"的客户端存储机制。
- `page-history` 功能是服务端记录的版本历史，非访问历史。
- localStorage 中无 `docmost:recent-pages` key（待新建）。

## 数据模型现状

```
pages 表（关键字段）：
  - id: string
  - parentPageId: string | null   ← 父级位置
  - position: string | null       ← 分数索引排序
  - spaceId: string               ← 所属 Space
  - nodeType: "file" | "folder"
```

- 当前 `POST /pages/move` 接受 `{ pageId, parentPageId, position }`：
  - `parentPageId = null` → 移至根级
  - `parentPageId = <id>` → 移至指定父级
  - `position` 当前必须为合法 fractional index 字符串
  - 本期 To-Be：`position = null` 或省略 → 后端计算并追加到目标子树末尾
