## 状态模型：MoveToModal Phase

```mermaid
stateDiagram-v2
  [*] --> idle : 打开 Modal
  idle --> searching : 输入关键词（debounce 触发）
  idle --> url_parsing : 检测到粘贴 URL
  idle --> selected : 点击最近访问列表项
  searching --> selected : 点击搜索结果项
  searching --> url_parsing : 搜索中途粘贴 URL
  url_parsing --> selected : URL 解析成功
  url_parsing --> idle : URL 解析失败（显示错误，保留列表）
  selected --> idle : 取消选中（点击已选项 或 清空输入）
  selected --> cross_space : 点击 Move Here（目标在不同 Space）
  selected --> moving : 点击 Move Here（同 Space）
  cross_space --> moving : 点击 Confirm Move
  cross_space --> selected : 点击 Cancel（返回选中态）
  moving --> done : API 成功
  moving --> selected : API 失败（error notification，保留选中）
  done --> [*] : 关闭 Modal
```

## 时序 1：打开弹窗 → 选择最近访问 → 同 Space 移动

```mermaid
sequenceDiagram
  participant U as User
  participant M as MoveToModal
  participant LS as localStorage
  participant API as Backend API
  participant QC as QueryClient

  U->>M: 点击"Move to..."
  M->>LS: getRecentPages(excludePageId)
  LS-->>M: RecentPageEntry[]（最多 6 条）
  M->>U: 展示最近访问列表

  U->>M: 点击列表中的"Design System"
  M->>M: setTargetPage(designSystem) / phase = selected
  M->>U: 展示选中预览 + 激活 Move Here

  U->>M: 点击 Move Here
  M->>M: phase = moving，Move Here 禁用
  M->>API: POST /pages/move { pageId, parentPageId: designSystem.id, position: null }
  API-->>M: 200 OK

  M->>QC: removeQueries ["sidebar-pages", "root-sidebar-pages"]
  M->>M: 清空本地 treeData，触发侧边树重载
  M->>M: phase = done
  M->>U: notification "Page moved successfully"
  M->>U: 关闭 Modal
```

## 时序 2：搜索 → 选择 → 跨 Space 移动

```mermaid
sequenceDiagram
  participant U as User
  participant M as MoveToModal
  participant SS as /search/suggest
  participant API as Backend API
  participant R as React Router

  U->>M: 输入"archive"（debounce 300ms）
  M->>SS: POST /search/suggest { query: "archive", includePages: true }
  SS-->>M: IPage[]
  M->>U: 展示搜索结果列表

  U->>M: 点击"Archive Folder"（spaceId != currentSpaceId）
  M->>M: setTargetPage(archiveFolder) / phase = selected
  M->>U: 选中预览（显示目标 Space 不同的徽章）

  U->>M: 点击 Move Here
  M->>M: phase = cross_space（检测到跨 Space）
  M->>U: 展示跨 Space 确认视图

  U->>M: 点击 Confirm Move
  M->>M: phase = moving
  M->>API: POST /pages/move-to-space { pageId, spaceId: targetSpaceId }
  API-->>M: 200 OK
  M->>API: POST /pages/move { pageId, parentPageId: archiveFolder.id, position: null }
  API-->>M: 200 OK

  M->>QC: removeQueries ["pages", "sidebar-pages", "root-sidebar-pages"]
  M->>M: phase = done
  M->>U: notification "Page moved successfully"
  M->>R: navigate(buildPageUrl(targetSpaceSlug, slugId))
  M->>U: 关闭 Modal
```

## 时序 3：粘贴 URL → 解析 → 移动

```mermaid
sequenceDiagram
  participant U as User
  participant M as MoveToModal
  participant API as Backend API

  U->>M: 粘贴 URL "/s/work/p/design-system-abc123"
  M->>M: 正则检测到 URL 格式，phase = url_parsing
  M->>API: POST /pages/info { pageId: "abc123", includeContent: false }
  
  alt 解析成功
    API-->>M: IPage { id, title, nodeType, spaceId, ... }
    M->>M: setTargetPage(parsed) / phase = selected
    M->>U: 展示选中预览
  else 解析失败（404 / 无权限）
    API-->>M: 404 / 403
    M->>M: urlError = "Page not found" / phase = idle
    M->>U: 输入框下方红色提示
  end
```

## 时序 4：页面访问时记录最近访问

```mermaid
sequenceDiagram
  participant R as Router
  participant P as page.tsx
  participant LS as localStorage

  R->>P: 路由就绪（pageId 变化）
  P->>P: useEffect 触发（deps: [page.id]）
  P->>LS: recordRecentPage({ pageId, title, icon, nodeType, spaceId, ... })
  LS->>LS: 去重更新 or FIFO 追加，保持 max 10 条
```

## 边界情况时序

### Case A：移动失败回退

```
moving → API 返回 4xx/5xx
  → phase 回退到 selected（保留 targetPage）
  → 展示 error notification
  → Move Here 按钮重新激活（用户可重试）
```

### Case B：跨 Space 移动第一步成功、第二步失败

```
POST /pages/move-to-space → 200
POST /pages/move → 500
  → 展示 notification:"Moved to space but failed to set location.
     Page is now at root of {{spaceName}}."
  → 清空 queryClient 缓存（因为 spaceId 已变更）
  → navigate 到目标 Space
  → 关闭 Modal（phase = done）
  → 用户可在目标 Space 中找到页面并再次移动
```

### Case C：Modal 关闭时未完成移动

```
moving 状态下用户关闭 Modal（点 × 或 Esc）
  → Modal 忽略关闭操作（moving 期间 Modal.Root closeOnEscape=false, closeOnClickOutside=false）
  → 移动完成后自动关闭
```
