# 04 风控与安全策略

**成文日期**：2026-03-08 03:12:15 UTC+8
**最后修订**：2026-03-08 03:14:26 UTC+8

本文档用于定义权限、限流、审计与安全策略。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## 核心原则

1. 预览体验不能突破分享访问控制。
2. 公开分享与受限分享必须分开设计，不能共用同一套元信息策略。
3. 分享预览中的标题、摘要、图片，都是“潜在泄露面”，必须按权限评估，而不是按营销诉求评估。

## 公开 / 受限分享安全边界

### 公开分享

允许：

- 标题
- 公开摘要
- 统一封面图或动态标题图
- canonical URL

要求：

- 仍遵守 `searchIndexing=false -> robots=noindex`
- 摘要必须从纯文本中提取，禁止注入 HTML、脚本或危险协议

### 受限分享

禁止：

- 暴露真实标题
- 暴露真实摘要
- 暴露真实封面图
- 暴露可推断正文内容的富预览字段

允许：

- 返回泛化标题或默认站点标题
- 返回最小必要的 `noindex`
- 返回可打开页面但不泄露文档语义的 canonical 形式

## canonical URL 风险控制

1. `shareKey` 仍为主定位键，slug 不参与权限判断。
2. URL 纠正逻辑必须基于真实 `shareKey + pageSlugId` 解析，不能基于标题模糊匹配。
3. redirect 只能跳向当前站点 canonical URL，禁止形成开放重定向。

## 预览图安全要求

1. 若使用动态 OG Image：
   - 输入必须只接受文本，不接受 HTML
   - 标题长度需截断
   - 图片接口需加缓存与限流
2. 若动态图生成失败，回退默认站点图，不允许把异常信息暴露给抓取方。

## 微信 JS-SDK 安全要求

1. 微信增强只在已配置、已验证域名中启用。
2. 签名接口不能泄露多余业务数据。
3. 前端只在微信 UA 下请求签名接口，避免无意义暴露。
4. 配置失败时必须静默降级，不影响正常页面访问。

## 审计与监控

至少监控以下问题：

1. 受限分享是否被错误注入真实标题或摘要
2. canonical redirect 是否出现错误跳转
3. 微信签名接口错误率
4. 预览图接口错误率
5. `searchIndexing=false` 时 `noindex` 是否缺失
