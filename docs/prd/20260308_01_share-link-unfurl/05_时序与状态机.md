# 05 时序与状态机

**成文日期**：2026-03-08 03:12:15 UTC+8
**最后修订**：2026-03-08 03:14:26 UTC+8

本文档用于定义时序流程与状态流转规则。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## Flow 1：公开分享被外部平台抓取

1. 外部平台访问分享 URL。
2. 服务端解析 `shareKey + pageSlugId`。
3. 若命中 legacy 路由或错误 slug，先纠正到 canonical URL。
4. 服务端识别为公开分享。
5. 生成：
   - 标题
   - 摘要
   - canonical
   - og/twitter 元信息
6. 返回带完整元信息的 HTML。
7. 外部平台自行决定是否展示预览卡片以及卡片样式。

关键点：

- 业务只能提供可抓取的高质量元信息，不能控制平台最终展示一定符合预期。

## Flow 2：受限分享被外部平台抓取

1. 外部平台访问分享 URL。
2. 服务端解析分享实体。
3. 识别为密码分享、过期分享或其他受限模式。
4. 不返回真实标题和摘要。
5. 返回泛化或最小元信息版本的 HTML。

关键点：

- 受限分享的“看起来没那么好看”是正确代价，不能为了好看破坏安全边界。

## Flow 3：用户复制分享链接

1. 用户点击“复制分享链接”。
2. 前端调用统一 URL builder。
3. builder 生成 canonical URL。
4. 写入剪贴板的永远是 canonical URL。

关键点：

- 复制动作不能继续输出 legacy 路由，否则外部传播形态永远无法统一。

## Flow 4：微信内打开后再次分享

1. 用户在微信内打开分享页。
2. 前端识别微信环境。
3. 请求微信签名接口。
4. 调用 `wx.config`。
5. 成功后调用：
   - `wx.updateAppMessageShareData`
   - `wx.updateTimelineShareData`
6. 用户通过微信菜单再次分享。

失败分支：

1. 签名接口失败
2. 域名未配置
3. 微信接口初始化失败

失败后的处理：

- 页面照常浏览
- 不阻塞正文
- 回退到服务端首屏元信息方案

## URL 状态机

### 输入状态

- `legacy_route`
- `canonical_route`
- `wrong_slug_route`

### 输出状态

- `render_public_meta`
- `render_restricted_meta`
- `redirect_canonical`
- `render_plain_index`

### 状态转换规则

1. `legacy_route` 且可解析 -> `redirect_canonical`
2. `wrong_slug_route` 且 `pageSlugId` 可解析 -> `redirect_canonical`
3. `canonical_route` 且公开分享 -> `render_public_meta`
4. `canonical_route` 且受限分享 -> `render_restricted_meta`
5. 任一状态解析失败 -> `render_plain_index` 或现有兜底逻辑
