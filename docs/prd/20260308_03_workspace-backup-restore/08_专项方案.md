## 专项主题

### 工作区级逻辑快照与“恢复到新工作区”方案

该专项用于解决两个最难问题：

1. 如何让备份真正是“工作区级”而不是“伪工作区级”
2. 如何在共享数据库中安全恢复，而不覆盖原工作区

## 方案总览

### 核心结论

1. 备份包格式必须是逻辑快照，不是 SQL dump。
2. 恢复目标必须是新工作区，不是原工作区。
3. 恢复实现必须依赖 ID 重映射与数据域白名单。

## 数据域专项范围

### 纳入矩阵

| 数据域 | 纳入方式 | 说明 |
| --- | --- | --- |
| Workspace 基础元信息 | 白名单字段导出 | 只导出名称、描述、部分非敏感 settings |
| Spaces | 全量导出 | 保留层级与 slug |
| Pages | 全量逻辑导出 | 恢复正文、树结构与非敏感属性 |
| Page History | 导出 | 保障历史版本可回看 |
| Attachments | 元数据 + 对象文件 | 保障内容完整恢复 |
| Comments | 导出 | 保留评论正文与基本状态 |
| Backlinks | 导出 | 恢复引用关系 |

### 排除矩阵

| 数据域 | 排除原因 |
| --- | --- |
| Shares | 公开访问风险高，且恢复到新工作区后旧链接语义不成立 |
| Workspace Members / Groups | 身份映射复杂，V1 不做 |
| Auth / Invitations / API Keys | 明确属于安全域，不由工作区备份克隆 |
| Billing / License | 实例商业域，不属于工作区内容 |

## 恢复到新工作区专项设计

### 为什么不是恢复到当前工作区

1. 当前工作区还活着，说明原数据仍有排障价值。
2. 原地覆盖意味着：
   - 需要停写
   - 需要完整回滚预案
   - 需要处理并发编辑与引用冲突
3. 对共享数据库而言，这不是 V1 能安全交付的能力。

### 目标工作区创建规则

1. 用户必须显式输入 `targetWorkspaceName`
2. 名称冲突直接报错，不做自动覆盖
3. apply 成功后返回新工作区路由和 ID

## 实体 ID 重映射专项

### 必须重映射的对象

1. 工作区
2. 空间
3. 页面
4. 附件
5. 评论

### 依赖重写的字段

1. `parentPageId`
2. `spaceId`
3. `workspaceId`
4. 页面内容 JSON 中的附件与内部链接引用
5. 评论关联字段

### 验收要求

1. 恢复后页面树结构与原工作区一致
2. 附件可访问
3. 页面内部引用不指回旧工作区资源

## 用户映射专项

### 设计

1. 备份包额外导出最小 actor 快照
2. 恢复时按 email 做 best-effort 匹配
3. 不匹配的 actor 不阻断恢复，但在报告中标红提醒

### V1 降级策略

1. 非必填创建人 / 更新人字段允许置空
2. 必填责任人字段回落当前操作人
3. 不自动恢复成员关系与权限继承

## 包格式专项

### 示例 `summary.json`

```json
{
  "workspace": {
    "name": "Engineering Workspace"
  },
  "counts": {
    "spaces": 3,
    "pages": 128,
    "attachments": 412,
    "comments": 56
  },
  "warnings": [
    "shares are excluded in v1",
    "memberships are excluded in v1"
  ]
}
```

### 验收要求

1. 包内必须同时有 `manifest.json` 与 `SHA256SUMS`
2. 缺任一关键文件时 dry-run 失败
3. 包格式版本不支持时必须给出明确错误

## COS 与本地下载专项

### 方案

1. 备份产物成功后立即上传 COS
2. 页面下载通过签名 URL 或代理下载完成
3. 本地下载不改变 COS 作为真源的定位

### 验收要求

1. COS 路径与工作区、年月、jobId 对齐
2. 下载链接默认短时效
3. 下载行为可追踪

## 专项风险

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 页面内容 JSON 引用重写遗漏 | 恢复后内部引用错乱 | 在 dry-run 与集成测试中增加引用检查 |
| 大附件导出慢 | 打包时间长 | 采用流式复制与进度摘要 |
| 用户映射误判 | 恢复后 attribution 异常 | 仅按 email 精确匹配，不做模糊匹配 |
