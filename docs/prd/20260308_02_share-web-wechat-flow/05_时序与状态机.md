# 05 时序与状态机

**最后修订**：2026-03-08 09:35:40 UTC+8

本文档用于定义时序流程与状态流转规则。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## Flow 1：桌面端微信分享

1. 用户在文档页点击右上角 `Share`
2. 弹出分享弹窗
3. 页面已生成公开分享链接
4. 弹窗内展示二维码
5. 用户使用微信扫码
6. 分享页在微信内打开
7. 用户使用微信右上角菜单发送给朋友或分享到朋友圈

## Flow 2：微信内浏览器

1. 用户已在微信内打开分享页
2. 用户点击 `Share`
3. 弹窗中显示原生分享引导文案
4. 用户点击微信右上角菜单
5. 用户手动选择好友或朋友圈

## Flow 3：手机非微信浏览器

1. 用户在 Safari/Chrome 中点击 `Share`
2. 弹窗中显示复制链接引导
3. 用户复制链接
4. 用户切到微信粘贴分享

## 状态机

### 输入状态

- `public_desktop`
- `public_mobile_wechat`
- `public_mobile_browser`
- `protected_any`

### 输出状态

- `show_qr_panel`
- `show_wechat_menu_hint`
- `show_copy_hint`
- `hide_wechat_qr`

### 转换规则

1. `public_desktop -> show_qr_panel`
2. `public_mobile_wechat -> show_wechat_menu_hint`
3. `public_mobile_browser -> show_copy_hint`
4. `protected_any -> hide_wechat_qr`
