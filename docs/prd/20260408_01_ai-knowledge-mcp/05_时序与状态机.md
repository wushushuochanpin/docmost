## 时序 1：连接外部 AI 客户端

```mermaid
sequenceDiagram
    participant U as User
    participant W as Web UI
    participant API as Token API
    participant MCP as /mcp
    participant AI as AI Client

    U->>W: 进入 /settings/account/api-keys
    U->>API: 创建只读 Token
    API-->>U: 返回一次性明文 Token
    U->>W: 进入 /settings/ai/mcp 复制 /mcp 地址
    U->>AI: 配置 server_url + Bearer Token
    AI->>MCP: 发起连接与工具发现
    MCP-->>AI: 返回只读工具清单
```

## 时序 2：AI 先搜索再抓正文

```mermaid
sequenceDiagram
    participant AI as AI Client
    participant MCP as MCP Gateway
    participant AUTH as Token/Scope Guard
    participant RET as Retrieval Service
    participant ACL as PageAccessService
    participant DB as Postgres

    AI->>MCP: search(query)
    MCP->>AUTH: 校验 token + scope + mcpEnabled
    AUTH-->>MCP: 通过
    MCP->>RET: 执行 hybrid retrieval
    RET->>DB: FTS/vector 查询
    RET->>ACL: 过滤不可访问页面
    ACL-->>RET: 可访问 page ids
    RET-->>MCP: 搜索结果 items[]
    MCP-->>AI: items[]
    AI->>MCP: fetch(id)
    MCP->>AUTH: 再校验 token + scope
    MCP->>RET: 获取正文
    RET->>ACL: 校验 page ACL
    RET->>DB: 读取页面正文
    RET-->>MCP: markdown content
    MCP-->>AI: document payload
```

## 时序 3：撤销 Token 后阻断 AI 调用

```mermaid
sequenceDiagram
    participant Admin as Admin/User
    participant API as Token API
    participant DB as sc_api_tokens
    participant AI as AI Client
    participant MCP as MCP Gateway

    Admin->>API: revoke(tokenId)
    API->>DB: status=revoked
    API-->>Admin: success
    AI->>MCP: search/fetch with old token
    MCP->>DB: validateApiToken
    DB-->>MCP: revoked
    MCP-->>AI: Unauthorized / Token revoked
```

## 状态机 3：索引同步

```mermaid
stateDiagram-v2
    [*] --> idle
    idle --> queued: page changed / workspace aiSearch enabled
    queued --> indexing: worker picked up job
    indexing --> ready: embeddings updated
    indexing --> failed: job failed
    failed --> queued: retry
```

## 关键状态规则

1. `mcpEnabled=false` 时，不允许任何工具调用进入执行态。
2. `token.status=revoked` 或 `expiresAt < now` 时，调用必须立即失败。
3. `search` 返回命中不代表 `fetch` 一定成功，`fetch` 必须二次 ACL 校验。
4. 索引失败不应阻断页面正常读写，但会降低 AI 检索质量。
