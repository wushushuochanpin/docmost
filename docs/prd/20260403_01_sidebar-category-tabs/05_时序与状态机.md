## 状态模型 1：节点分类状态

```mermaid
stateDiagram-v2
  [*] --> Uncategorized
  Uncategorized --> Categorized: assign(categoryId)
  Categorized --> Uncategorized: clearCategory
  Categorized --> Uncategorized: deleteCategory
  Categorized --> Uncategorized: moveUnderParent
  Categorized --> Uncategorized: moveToAnotherSpace
  Categorized --> Categorized: reassign(categoryId')
```

### 说明

- `Categorized` 仅允许存在于首级节点。
- 一旦节点失去首级身份，必须回到 `Uncategorized`。

## 状态模型 2：侧边栏视图状态

```mermaid
stateDiagram-v2
  [*] --> All
  All --> Pinned: switchToPinned
  All --> Category: switchToCategory
  Pinned --> All: switchToAll
  Pinned --> Category: switchToCategory
  Category --> All: switchToAll
  Category --> Category: switchCategory
  Category --> All: currentPageOutsideView
```

### 说明

- `Pinned` 与 `Category` 都只是根视图过滤态。
- `currentPageOutsideView` 是本期关键保护分支，不能省略。

## 时序 1：打开页面并加载侧边树

```mermaid
sequenceDiagram
  participant U as User
  participant C as Client
  participant P as Page API

  U->>C: 进入页面
  C->>C: 读取 space 级已选 viewMode/categoryId
  C->>P: POST /pages/sidebar-pages (root query)
  P-->>C: 返回根节点列表
  C->>C: 检查当前页面所属根节点是否在结果中
  alt 当前页在结果中
    C->>C: 正常渲染树并按需补齐祖先
  else 当前页不在结果中
    C->>C: 切回 viewMode=all
    C->>P: POST /pages/sidebar-pages (all)
    P-->>C: 返回全部根节点
    C->>C: 渲染树并补齐当前页路径
  end
```

## 时序 2：给首级节点设置分类

```mermaid
sequenceDiagram
  participant U as User
  participant C as Client
  participant P as Page API
  participant D as DB

  U->>C: 在根节点菜单中选择分类
  C->>P: POST /pages/sidebar-category/assign
  P->>D: 校验 page 为根节点且 category 属于同 Space
  D-->>P: 校验通过
  P->>D: 更新 page_node_meta.sidebar_category_id
  P-->>C: 返回成功
  C->>C: 失效 root-sidebar-pages 和 sidebar-categories 查询
  C->>C: 重新渲染当前视图
```

## 时序 3：删除分类

```mermaid
sequenceDiagram
  participant U as User
  participant C as Client
  participant S as Category API
  participant D as DB

  U->>C: 确认删除分类
  C->>S: POST /spaces/sidebar-categories/delete
  S->>D: 事务开始
  S->>D: 将关联节点 sidebar_category_id 置空
  S->>D: 删除分类记录
  D-->>S: 提交事务
  S-->>C: 返回 unassignedRootCount
  C->>C: 若当前选中为该分类，则回退全部
  C->>C: 刷新分类列表与根树
```

## 时序 4：根节点移动导致分类失效

```mermaid
sequenceDiagram
  participant U as User
  participant C as Client
  participant P as Page API
  participant D as DB

  U->>C: 将根节点拖入某个文件夹
  C->>P: 现有 move/batch-move 接口
  P->>D: 更新 parent_page_id
  P->>D: 检测节点已非根级，清空 sidebar_category_id
  D-->>P: 提交
  P-->>C: 返回成功
  C->>C: 刷新根树与相关视图
```

## 状态与时序结论

1. 本期最关键的状态边界是“首级/非首级”。
2. 本期最关键的时序保护是“当前页不在当前视图时切回全部”。
3. 只要这两条规则被稳定执行，分类 Tab 就能与现有树模型共存。
