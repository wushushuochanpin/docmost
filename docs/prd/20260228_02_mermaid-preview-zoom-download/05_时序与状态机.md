## 时序图：打开预览并交互

```mermaid
sequenceDiagram
  participant U as User
  participant V as MermaidView
  participant M as PreviewModal

  U->>V: 单击 Mermaid 图
  V->>M: open(svg)
  M-->>U: 展示遮罩 + 初始 100%

  U->>M: 捏合/滚轮/按钮缩放
  M->>M: update scale + translate
  M-->>U: 实时重绘 transform

  U->>M: 拖拽
  M->>M: update translateX/Y
  M-->>U: 平移视图

  U->>M: 下载 PNG/SVG
  M->>M: 生成 blob 并保存
  M-->>U: 下载成功/失败提示

  U->>M: Esc/点击遮罩/关闭按钮
  M->>V: close
```

## 状态机：预览器

```mermaid
stateDiagram-v2
  [*] --> Closed
  Closed --> Opened: click mermaid
  Opened --> Zooming: wheel/gesture/button
  Zooming --> Panning: pointer drag when scale > 1
  Panning --> Zooming: pointer up
  Zooming --> Downloading: click download
  Downloading --> Zooming: success or fail
  Opened --> Closed: esc | maskClick | closeBtn
  Zooming --> Closed: esc | maskClick | closeBtn
  Panning --> Closed: esc | maskClick | closeBtn
```

## 关键状态约束

1. `Closed` 进入 `Opened` 时，重置 `scale=1, translate=(0,0)`。
2. `scale <= 1` 时不允许进入 `Panning`。
3. 关闭动作优先级最高，任意状态均可直接关闭。
