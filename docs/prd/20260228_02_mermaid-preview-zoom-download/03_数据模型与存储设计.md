## 数据库与服务端存储

- 数据库表：无新增、无变更。
- 服务端缓存：无新增。
- 迁移脚本：无。

## 前端运行时状态模型

| 状态键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| opened | boolean | false | 预览遮罩是否打开 |
| scale | number | 1 | 当前缩放比例 |
| translateX | number | 0 | 当前 X 方向平移 |
| translateY | number | 0 | 当前 Y 方向平移 |
| isDragging | boolean | false | 是否处于拖拽平移中 |
| dragStartX | number | 0 | 拖拽起始点（瞬态） |
| dragStartY | number | 0 | 拖拽起始点（瞬态） |

## 文件导出数据

- SVG 下载 MIME：`image/svg+xml`。
- PNG 下载 MIME：`image/png`。
- 文件名策略：`mermaid-diagram-{timestamp}.svg|png`。

## 可观测性（可选埋点，非阻塞）

| 事件名 | 触发条件 | 字段 |
| --- | --- | --- |
| mermaid_preview_open | 打开预览 | pageId, source=click |
| mermaid_preview_zoom | 缩放 | pageId, scale, source=button/wheel/gesture |
| mermaid_preview_download | 下载 | pageId, format=png/svg, success |

说明：若本项目当前无统一埋点框架，本期可以先不接入。

## 数据一致性与回滚

- 本期状态均为前端临时态，不落库。
- 回滚时无需数据修复，仅代码回退。
