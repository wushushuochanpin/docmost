# 04 风控与安全策略

**成文日期**：2026-02-28 15:07:59 UTC+8
**最后修订**：2026-02-28 15:07:59 UTC+8

本文档用于定义权限、限流、审计与安全策略。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## 权限策略

- 复用现有页面访问权限。
- Mermaid 预览与下载不新增独立角色控制。
- 编辑权限不作为预览前置条件（阅读用户也可预览与下载）。

## 安全控制

1. XSS 风险
- Mermaid 渲染结果继续走现有渲染路径与错误处理。
- 下载使用当前已渲染 SVG，不执行额外脚本。

2. 资源释放
- 下载过程创建的 Blob URL 需及时 `URL.revokeObjectURL`。
- Modal 关闭时清理事件监听，避免泄露。

3. 文件安全
- 仅下载用户当前可见图表，不引入跨文档数据。
- 文件名采用固定前缀 + 时间戳，不拼接用户输入。

## 兼容与异常兜底

- 浏览器不支持手势事件时，保留按钮缩放和滚轮缩放。
- `canvas.toBlob` 返回空时提示失败并允许重试。
- 下载失败不影响预览基本功能。

## 审计建议

- 可在控制台输出错误码（仅开发环境），生产环境走统一错误上报。
- 如后续出现高频下载失败，再补充埋点与告警阈值。
