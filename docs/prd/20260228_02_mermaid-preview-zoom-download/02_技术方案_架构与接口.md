# 02 技术方案：架构与接口

**成文日期**：2026-02-28 15:07:59 UTC+8
**最后修订**：2026-02-28 15:07:59 UTC+8

本文档用于定义技术架构、接口契约与兼容策略。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## 实现范围

- 仅改动客户端：`apps/client/src/features/editor/components/code-block/`。
- 不新增后端 API、数据库字段或消息总线。

## 模块设计

1. `mermaid-view.tsx`
- 保留现有 Mermaid 渲染逻辑（`mermaid.render`）。
- 新增单击打开预览行为。
- 持有 `opened`、`preview` 等状态并传给预览弹层组件。

2. `mermaid-preview-modal.tsx`（新增）
- 职责：展示遮罩、承载缩放平移状态、处理输入手势、提供下载功能。
- 核心状态：
  - `scale: number`（默认 1，范围建议 0.25~4）
  - `translateX/translateY`
  - `isDragging: boolean`
- 核心事件：
  - `onWheel`（含 ctrlKey 捏合场景）
  - `gesturestart/gesturechange`（Safari 触控板）
  - `pointerdown/move/up`（拖拽平移）

3. `code-block.module.css`
- 新增 Mermaid 可点击样式与 Modal 内容样式。

## 交互与算法细节

### 缩放

- 统一入口 `applyScale(nextScale, anchorX, anchorY)`：
  - 先 clamp 缩放范围；
  - 以锚点（鼠标/手势中心）计算平移补偿，保证缩放焦点稳定；
  - 更新 transform。

### 触控板捏合兼容

- Chromium：`wheel` 事件中 `ctrlKey === true` 视作 pinch。
- Safari：监听 `gesturestart` / `gesturechange`，以 `event.scale` 增量计算。
- 事件仅在 Modal 打开后注册，关闭时解除。

### 平移

- 当 `scale > 1` 时允许拖拽平移。
- 使用 pointer events，避免 mouse/touch 双栈维护。

### 下载

- SVG：
  - 从已渲染 SVG 字符串创建 Blob（`image/svg+xml`）；
  - 使用 `file-saver` 触发下载。
- PNG：
  - SVG Blob -> Image -> Canvas 绘制 -> `canvas.toBlob('image/png')`；
  - 再由 `file-saver` 下载。

## 接口契约

- 后端接口：无新增。
- 组件入参（新增组件内部契约）：
  - `opened: boolean`
  - `onClose: () => void`
  - `svg: string`
  - `title?: string`

## 兼容性

- 编辑态与阅读态均支持打开预览（按单击触发）。
- 移动端无捏合事件时至少保留按钮缩放能力。
- 不影响非 Mermaid 代码块。

## 性能约束

- 仅在预览打开时挂载手势监听。
- 不引入重型三方库，维持轻量包体。
- Mermaid SVG 直接复用已渲染结果，避免重复 render。

## 错误处理

- Mermaid 渲染失败时沿用现有错误 UI，不开启预览。
- PNG 转换失败时提示下载失败（不影响 SVG 下载）。
