# 04 风控与安全策略

**成文日期**：2026-03-08 20:57:06 UTC+8
**最后修订**：2026-03-08 20:58:36 UTC+8

本文档用于定义升级过程中的风控、安全、权限和发布门槛。阅读时当前系统实现可能已发生变化，请以实际代码与产品行为为准，谨慎参考。

---

## 风控目标

1. 升级过程中不发生本地已上线能力回退。
2. 不因上游 `feat(ee)` 模块引入启动失败、入口错配或未授权访问。
3. 不因 migration 误执行破坏现有多租户/RLS、分享、备份语义。
4. 不因部署文件替换暴露额外公网端口或破坏当前 Nginx 入口模式。

## 风险分级

| 风险域 | 风险描述 | 等级 | 风控策略 |
| --- | --- | --- | --- |
| 数据迁移 | 迁移重命名或重复执行导致 schema 漂移 | critical | 保留本地 migration 文件名，所有新增迁移先在 staging 演练 |
| 权限 | page permissions 与本地 RLS/folder-first 叠加出错 | high | 默认隐藏入口，先完成联动回归再决定开放 |
| 分享 | 上游分享修复覆盖本地微信/SSR/static 逻辑 | high | 本地 share 代码列为保护域，只 cherry-pick 补丁 |
| 备份 | 上游无等价模块，本地备份域被覆盖或依赖断裂 | high | 备份域整体保护，单独 smoke test |
| EE gating | UI 可见但后端模块未加载或 license 不满足 | high | 前后端双重 gating，启动期容错 |
| 部署 | 官方 compose 公开端口、切换镜像模型 | high | 保留本地部署模型，不引入官方默认 compose |
| 依赖 | 大版本依赖升级导致构建失败或运行时不兼容 | medium | 锁定升级分支统一解依赖，编译和 smoke test 双门槛 |

## 安全原则

1. 所有新增入口默认关闭，直到接口、权限、回归全部通过。
2. 所有外部可见公开链路优先保护本地分享页行为。
3. 所有涉及管理员写操作的新能力需要二次确认或明显的危险提示。
4. 所有敏感配置变量采用“本地已存在变量保留 + 上游新增变量可选”的兼容方式。

## 权限与安全矩阵

| 能力 | 前端可见条件 | 后端校验条件 | 风控要求 |
| --- | --- | --- | --- |
| Page permissions | workspace admin + feature gate | page access service + 本地权限/RLS | 默认关闭，staging 验证后开放 |
| Audit logs | admin + enterprise access | audit module loaded + license valid | 无后端模块时入口不可见 |
| MCP | admin + enterprise access | MCP server/module available | 对外入口需和 license 联动 |
| AI menu | enterprise access + AI 配置齐备 | AI driver/license valid | 未配置模型时不展示 |
| User deactivation | workspace admin | workspace service role check | 需要误停用确认与日志 |
| Backup | admin/ops | 本地 backup controller 权限 | 保持现有本地策略，不受上游影响 |

## 配置安全

### 本地必须保留

1. `APP_CHANNEL`
2. `WECHAT_APP_ID`
3. `WECHAT_APP_SECRET`
4. `BACKUP_LOCAL_PATH`
5. 当前 `APP_URL`、`DATABASE_URL`、`REDIS_URL`、对象存储配置

### 上游可兼容引入但默认不开启

1. `EVENT_STORE_DRIVER`
2. `CLICKHOUSE_URL`

### 配置风险控制

1. 环境变量校验需要同时兼容本地微信/备份变量与上游 event store 变量。
2. 升级后 `.env.example` 不能丢失本地变量说明。
3. 部署脚本不可切换为官方公开 `3000:3000` 暴露模型。

## 发布门槛

| 门槛项 | 通过条件 |
| --- | --- |
| 代码构建 | `pnpm build` 通过 |
| 数据迁移 | staging 全量执行通过且 schema 校验通过 |
| 核心回归 | 树、编辑器、分享、备份、设置页、登录回跳全部通过 |
| 安全校验 | EE gating、权限拦截、公开分享访问控制全部通过 |
| 回滚演练 | 至少一次完整版本回滚演练成功 |

## 事故触发器

满足任一条件时立即停止继续放量并执行回滚或入口关闭：

1. 编辑器主链路不可用。
2. 分享页返回 5xx 或页面结构严重异常。
3. 备份任务无法创建、查看或下载。
4. 权限越权或页面无法访问。
5. 启动时 enterprise 模块加载失败导致主进程异常。

## 回滚优先级

1. 先关入口和 feature gate。
2. 再回退应用版本。
3. 最后才评估数据库层补救动作。
