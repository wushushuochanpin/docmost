## 背景与目标

- [x] 背景问题：当前文档编辑页面仅提供默认的白色背景，缺乏个性化表现。现代文档工具（如飞书、Notion等）已普遍支持底色和页面纹理切换，有助于满足头脑风暴（如点阵）、技术笔记（如网格）等多场景需求，并提供护眼模式等沉浸式体验。
- [x] 目标指标：在文档阅读和编辑页提供可选的“页面样式（底色+底纹）”设置，且将其作为文档级别的元数据保存。使用户和协作者不仅在自己设备上，甚至别人打开同一文档时也能感受到统一风格。

## 现状审计（As-Is）

- [x] 现有页面/交互：编辑器页面右上角仅有基础的更多操作，无页面级背景样式设置入口。页面背景硬编码为 CSS 变量中的默认背景色。
- [x] 现有数据表盘点：文档 (Document) 数据结构中，未预留页面主题控制的相关元数据字段。
- [x] 现有权限：页面样式的修改权限应与文档本身的“编辑权限”一致。只读者（Viewer）无权修改样式。

## 菜单入口与前端逐页说明

### PAGE-DOC-EDITOR (文档编辑/阅读页)

- **页面目的**：支持用户设置当前文档的底色和底纹，并实时生效。
- **入口位置**：文档编辑/阅读页右上角「 `...` (更多) 」菜单内，新增「页面样式 (Page Style)」入口。
- **权限控制**：
  - 可见：所有用户。
  - 操作：仅在“编辑模式（拥有 Edit 权限）”下「页面样式」为可点击状态。若无权，则该 Menu 被 disable 且 hover 提示“仅编辑者可修改”。
- **交互与组件**：
  - 此项点击后，通过 **Popover 气泡卡片** 展开。
  - **组件区 1（纯色面）**：横向排列 6 个低饱和度颜色块（包含透明/恢复默认项：白、护眼黄、莫兰迪绿、静灰蓝、樱花粉）。基于 `theme_color`。
  - **组件区 2（纹理面）**：并排陈列 4 个卡片，缩略图示例（空白 Blank、点阵 Dot Grid、网格 Grid、横线 Ruled）。基于 `theme_pattern`。
  - 选中任何一项即时生效预览（纯前端修改，防抖触发保存 API）。
- **异常与状态**：
  - 兼容深色模式（Dark Mode）：如果是深色模式，强烈建议**强制收敛彩色背景为暗灰色阶**，或者仅允许切换底纹（禁用彩色底色），以免高亮色域反差刺眼。
- **埋点**：
  - 触发“设置页面样式” Popover 曝光；
  - 切换底色/底纹操作日志。

## 改造影响矩阵与灰度切换

- [x] impact_matrix：
  - 现状行为：文档统一白/黑底。目标行为：根据元数据带不同 CSS 渲染。仅影响前端渲染与存储字段层。
- [x] 灰度策略：前端基于特性开关控制入口展示。
- [x] 回滚策略：直接关闭特性开关，前端渲染容错（若发现未知样式数据，均 fallback 回归默认白板）。

## 验收标准

- [ ] 功能验收：各种排版底色/底纹在 PC 与不同视口下渲染正常（底纹必须用 CSS 实现而非图片）。
- [ ] 边界验收：在 Dark Mode 深色模式下的表现符合色彩预期（无刺眼的亮彩色跳跃）。
- [ ] 权限验收：无权限读者看得到样式变更，但看不到且无法点击设置入口。
