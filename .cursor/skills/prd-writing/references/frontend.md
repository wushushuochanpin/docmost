# PRD 前端页面标注规范与逐页模板

前端标注以**页面 → 区块 → 组件/字段 → 操作**层级组织，每对象给**唯一 ID**（page_id、section_id、component_id、action_id），便于可追踪与机器生成。

## 何时使用

- 撰写 PRD 中「前端页面逐页说明」时。
- 评审列表/详情/编辑/弹窗/设置页是否写到字段粒度、是否含空态/错误态/权限/埋点时。

## 强制标注字段（每页必写）

- 页面目的：解决什么问题；主要用户是谁。
- 入口位置：菜单路径/路由/外链/带参规则。
- 权限控制：可见权限、可操作权限；无权限提示（如“搜索结果中部分无权查看已过滤”）。
- 数据来源：列表来自哪个接口；字段映射；刷新时机。
- 交互规则：排序、分页、筛选联动、hover、弹窗、跳转、吸顶/吸底等。
- 异常与状态：loading、空态、无权限、错误码提示与恢复操作。
- 埋点：事件名、触发时机、字段；粒度（每点击一次/每次保存一次）。
- 响应式/移动端：是否需要；未指定则写“未指定/默认 PC”。
- 无障碍：键盘可达、可读标签、焦点可见、错误提示可感知；参考 WCAG 2.2 与 WAI-ARIA。

## 列表页要点摘要

- 表格区：默认排序、分页（page_size 默认/可选/最大）、表头与列定义（列名、field_key、类型、展示格式、宽度、是否默认展示、是否可排序）。
- 分页器设计：必须明确分页模式（offset/token）、是否展示总数、页码与跳页能力、上一页/下一页/首页/末页、分页器禁用态、筛选/排序变更后的翻页重置规则。
- 分页一致性：必须明确稳定排序字段（主排序 + 次排序），避免翻页重复/遗漏；涉及实时数据时要写清“快照分页”或“最终一致”策略。
- 分页可用性与异常：必须定义空页回退（例如删除后当前页为空时跳上一页）、请求失败重试、加载态骨架、无障碍键盘可达和读屏标签。
- 搜索与筛选：筛选项（字段、控件类型、默认值、必填、联动）；搜索项（精确/模糊/范围、大小写、分词、高亮）。
- 操作列与批量操作：单行操作（名称/条件/二次确认/成功失败提示）；批量（选择规则/最大条数/部分失败/导出任务策略）。
- 列表页示范：时间筛选可必填、默认“当天 0:00-23:59”+ 快捷选项；表头可自定义；无权限结果提示“已过滤”。

## 详情页要点摘要

- 安全：直达链接避免明文 ID；无权限不可打开并提示。
- 信息结构：分区（基础信息/业务关联/日志/附件/操作记录）；字段展示含取值来源、格式、脱敏。
- 操作区：可执行动作、状态前置条件（状态机）、二次确认、失败恢复；关键动作可追溯。

## 新增/编辑页要点摘要

- 表单项：字段 key/中文名/类型/必填/默认值；校验规则（长度、范围、枚举、跨字段）；错误提示文案。
- 保存：触发时机、幂等、是否更新版本号；成功后跳转与刷新。防短时重复点击需在后端幂等配合。

## 弹窗与设置页摘要

- 弹窗：modal_id、触发入口、目的与决策点、主/次按钮与默认焦点、校验与关闭后刷新/回填；无障碍：焦点锁定、Esc 关闭、aria-label。
- 设置页：配置项 key/类型/默认值/生效范围（全局/角色/个体）/生效时机（即时/重启/发版）；高危配置需审批/二次确认；配置变更日志。若灰度等不做页面配置而走后端配置，PRD 需写清原因与替代方式。

## 无障碍与响应式

- 未指定则默认 PC 固定宽度；若需移动端则补齐触控、目标尺寸、焦点可见。WCAG 2.2、WAI-ARIA 与 APG 可作为无障碍章节的权威依据。

## 改造类需求必填：交互影响与灰度切换

### 交互影响模板

| 页面ID | 现状交互 | 改造后交互 | 受影响角色 | 兼容策略 | 灰度方式 | 兜底文案 |
|---|---|---|---|---|---|---|
| PAGE-001 | ... | ... | ... | ... | ... | ... |

### 说明

- 若入口、按钮位置、操作路径发生变化，必须给“旧路径兼容期”。
- 若灰度不走前端开关，必须写清“后端开关位置与前端感知方式”。
- 无权限/过滤提示文案变更，必须纳入回归用例。

## 列表页模板

- page_id / page_name
- 页面目的
- 入口位置（菜单路径/路由/外链；是否支持带参打开）
- 权限控制
  - 可见：{角色列表}
  - 操作：{操作→角色}
  - 无权限策略：过滤/置灰/提示文案
- 表格区
  - 默认排序：{字段 + asc/desc}
  - 分页器（必填）
    - pagination_mode：{offset / token}
    - page_size：{默认值、可选值、最大值}
    - total_count_mode：{exact / estimated / unknown}
    - 翻页控件：{首页/上一页/下一页/末页/页码输入跳转}
    - 翻页状态：{可点击条件、禁用条件、加载态}
    - 重置规则：{筛选/搜索/排序变化后是否重置到第一页}
    - 一致性规则：{主排序字段 + 次排序字段；是否快照分页}
    - 异常策略：{请求失败重试、空页回退、超时提示}
    - 无障碍：{键盘焦点顺序、aria-label、读屏提示}
  - 表头与列定义（逐列一行）：
    - 列名（中文）/ field_key / 数据类型（string/int/enum/datetime/amount）
    - 展示格式（日期格式/金额单位/脱敏规则）
    - 宽度建议（px 或比例）
    - 是否默认展示 / 是否支持自定义显示
    - 是否支持排序（Y/N；若 Y，排序字段白名单）
- 搜索与筛选区
  - 筛选项（逐项）：字段、控件类型（select/多选/日期范围/输入框）、默认值、是否必填、联动规则
  - 搜索项：精确/模糊/前缀/后缀/包含；大小写；分词；高亮
- 操作列与批量操作
  - 单行操作：{操作名称/触发条件/二次确认/成功提示/失败提示}
  - 批量操作：{选择规则/最大条数/部分失败策略/导出任务策略}
- 展示与交互逻辑
  - hover/tooltip/省略号/展开折叠
  - 跳转规则（是否新开 tab；是否带参；参数加密/脱敏）
- 错误/空状态
  - 空态文案 + 引导操作
  - 错误态：重试、联系支持、错误码展示策略
- 埋点
  - 页面曝光、筛选、排序、点击操作、导出等事件与字段
- 响应式/无障碍要点

### 列表页 Checklist

| 检查项 | 通过标准 |
|---|---|
| 权限可见与可操作是否分离 | “看得见≠能操作”，且后端有强校验点 |
| 每列字段是否可映射到接口字段 | field_key 与 API 字段一致或有映射表 |
| 筛选/搜索匹配逻辑是否可测试 | 明确“精确/模糊/范围/枚举”与大小写规则 |
| 默认排序是否稳定 | 明确主排序字段；必要时追加次排序 |
| 分页器规则是否完整 | 明确模式、总数策略、跳页、重置规则、禁用态 |
| 分页结果是否可验证 | 翻页无重复/遗漏；删除后空页回退行为明确 |
| 空态/错误态是否可恢复 | 至少提供重试/返回/联系路径 |
| 是否描述批量操作边界 | 最大条数、异步导出、部分失败说明 |
| 是否有埋点粒度 | “每点击一次一条/每次保存一次”等 |

示范：时间筛选可设为必填、默认“当天 0:00-23:59”，并提供快捷选项；表头可自定义显示；无权限结果需要提示“已过滤”。

## 详情页模板

- page_id / page_name
- 入口：列表点击/外链直达/带参打开
- 安全要求：链接参数是否可明文；是否需简单加密；无权限直达的提示
- 信息结构：分区（基础信息/业务关联/日志/附件/操作记录）
- 字段展示：字段名、取值来源、格式、脱敏规则
- 操作区：可执行动作、状态前置条件（状态机约束）、二次确认、失败恢复
- 历史/版本：是否支持版本查看；切换规则
- 埋点：查看、复制、下载、执行动作等
- 无障碍：标题结构、跳转焦点、按钮语义化标签

### 详情页 Checklist

| 检查项 | 通过标准 |
|---|---|
| 是否定义“直达链接”安全策略 | 避免明文 ID；无权限不可打开 |
| 字段是否覆盖业务验收所需信息 | 验收人员可用详情页核对结果 |
| 动作是否有状态约束 | 每个动作写清“允许状态/禁止状态” |
| 是否有操作记录/审计需求 | 关键动作必须可追溯 |

示范：工单详情页建议“独立链接、勿直接拼接工单ID明文、需权限控制、无权提示”。

## 新增/编辑页模板

- page_id / page_name
- 入口：按钮/快捷入口/复制新建
- 表单项逐项定义：
  - 字段 key / 中文名 / 数据类型 / 是否必填 / 默认值
  - 校验规则：长度、范围、枚举、跨字段联动
  - 错误提示文案（面向用户）
- 保存/暂存/提交：
  - 保存触发时机；是否需要幂等；是否更新版本号
  - 成功后跳转与刷新策略
- 附件/富文本：格式限制、大小、下载权限
- 埋点：保存、校验失败、上传等

### 新增/编辑页 Checklist

| 检查项 | 通过标准 |
|---|---|
| 必填项是否完整且有提示 | 缺失必填时提示一致且可理解 |
| 是否定义保存幂等/防重复 | 重复点击不产生重复写入 |
| 是否定义版本/处理轮次等规则 | 变更是否会更新版本号、轮次等 |

示范：保存类操作若信息变更则更新版本号；并明确“需要设计防短时重复点击”。

## 弹窗模板

- modal_id / 触发入口
- 弹窗目的与用户决策点
- 字段与按钮：主按钮/次按钮/关闭；默认焦点
- 校验与错误提示
- 关闭后页面刷新/回填策略
- 无障碍：焦点锁定、Esc 关闭、aria-label

---

## 设置页模板

- setting_id / 配置项列表
- 配置项字段：key、类型、默认值、生效范围（全局/角色/个体）、生效时机（即时/重启/发版）
- 安全：高危配置需审批/二次确认
- 审计：配置变更日志

说明：当配置项影响面大或权限高时，应明确是否做配置页面；若不做（如灰度控制为降低成本走后端配置文件），则在 PRD 写清原因与替代方式。
