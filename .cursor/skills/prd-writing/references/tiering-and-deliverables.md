# PRD 档位与交付策略（用于 prd-writing）

用于在 `small / medium / large` 三档之间做一致判定，并明确不同档位的最小交付内容。

## 判档原则（风险优先）

1. 影响面：单端 / 双端 / 多系统。
2. 变更类型：配置变更 / 接口字段变更 / 破坏式变更。
3. 风险等级：回退复杂度、权限边界、多租户隔离、审计合规。
4. 架构深度：是否涉及规则中心、中台治理、链路重构。

## 档位规则

### small

- 场景：单团队、低风险、无破坏式变更、无需跨系统联动。
- 文档形态：允许单文档 PRD，不强制整套多文档。
- 最小内容：目标范围、现状审计、影响面矩阵、测试回归、回滚方案。

### medium

- 场景：跨前后端或跨系统，存在接口或字段变更。
- 文档形态：建议专题包（README + 01~06）。
- 最小内容：small 全部内容 + 接口契约 + 数据迁移 + 灰度方案。

### large

- 场景：跨域架构改造、中台化、涉及高合规或高可用风险。
- 文档形态：建议扩展包（Standard + 00/07/08/09）。
- 最小内容：medium 全部内容 + 现状审计专项 + 评审意见闭环 + 未来演进边界。

## 默认与升级规则

1. 信息不足时默认 `medium`。
2. 发现以下任一条件，自动升级档位：
- 破坏式变更（删除字段/语义反转/不可逆迁移）。
- 跨系统联动（多服务或多团队协作发布）。
- 租户隔离或权限边界调整。
- 高风险写链路重构（需要强制 re-check）。

## 档位兼容映射

- `small <-> lite`
- `medium <-> standard`
- `large <-> extended`

## 对应脚本（位于 prd-writing/scripts）

- `next_prd_index.sh`：计算当天自增序号。
- `init_prd_package.sh`：按档位初始化 PRD 包骨架。
- `validate_prd_package.sh`：按档位做命名、结构与内容门槛校验。
